Was ist BlockIt? Zum Seitenanfang

Websites, die Werbung anzeigen, und beliebte Werbeblocker befinden sich in einem ständigen "Wettrüsten": Entwickler finden immer neue Wege, um Ihnen Werbung zu zeigen, und Blocker finden Wege, sie zu verstecken.

BlockIt bietet einen anderen Ansatz. Anstatt sich auf gemeinsame Filterlisten zu verlassen, erstellen Sie eigene Regeln, um bestimmte Elemente zu blockieren. Ihre Regeln bleiben nur Ihnen bekannt, es sei denn, Sie entscheiden, sie zu teilen, was sie viel widerstandsfähiger gegen Umgehungen macht.

Hauptfunktionen:

  • Einfache Bedienung: Kopieren Sie einfach einen Selektor aus den Entwicklertools und fügen Sie ihn in die Erweiterung ein.
  • Flexibilität:
    • Unterstützt sowohl CSS-Selektoren als auch XPath-Ausdrücke
    • Sie entscheiden, ob Sie ein Element entfernen oder ausblenden
    • Sie entscheiden, welche Elemente blockiert werden sollen und welche nicht
    • Sie entscheiden, welche Blockierungsregeln behalten und welche gelöscht werden sollen
  • Privatsphäre: Alle Regeln werden lokal in Ihrem Browser gespeichert und nirgendwohin gesendet.
  • Seitenbasierte Gruppierung: Regeln werden automatisch für die aktuelle Seite und für alle anderen gruppiert. Das erleichtert die Verwaltung.
  • Einstellungen teilen: Sie können Ihre Regeln mit anderen Benutzern teilen, indem Sie sie in eine Datei exportieren.
  • Mehrsprachige Unterstützung: Die Oberfläche der Erweiterung wechselt automatisch zur Sprache, die in Ihrem Browser eingestellt ist. Unterstützte Sprachen: Russisch, Englisch, Französisch, Deutsch, Spanisch, Portugiesisch, Chinesisch und Japanisch. Wenn Ihre Sprache nicht unterstützt wird, wird die Oberfläche auf Englisch angezeigt (Standardsprache).
  • Open Source: Die Erweiterung wird unter der BSD-3-Clause-Lizenz entwickelt. Sie können am Projekt mitwirken, Verbesserungen vorschlagen und den Code auf GitHub einsehen.

Schnellstart Zum Seitenanfang

Installation

Methode 1 (empfohlen): Gehen Sie in den Chrome Web Store, suchen Sie die BlockIt-Erweiterung und klicken Sie auf "Installieren". Nach der Installation sollten Sie die Erweiterung in der Symbolleiste des Browsers anheften, indem Sie auf das Puzzle-Symbol neben der Adressleiste klicken und "Anheften" neben BlockIt auswählen.

Methode 2 (für Entwickler): Laden Sie den Quellcode von GitHub herunter und laden Sie die entpackte Erweiterung.

Wie blockiere ich ein Element

  1. Klicken Sie mit der rechten Maustaste auf das Element, das Sie blockieren möchten, und wählen Sie "Untersuchen" (oder "Element untersuchen"). Diese Aktion führt Sie immer direkt zum Element im HTML-Baum.
  2. Finden Sie das gewünschte Element im HTML-Baum. Um sicherzustellen, dass Sie das richtige Element ausgewählt haben, fahren Sie mit dem Mauszeiger über die Codezeilen – die entsprechenden Elemente auf der Seite werden hervorgehoben. Wählen Sie das äußerste Element, das den Block, den Sie blockieren möchten, vollständig abdeckt.
  3. Klicken Sie mit der rechten Maustaste auf das Element im Baum → Kopieren → Selektor kopieren (oder Copy selector). Für XPath: XPath kopieren (oder Copy XPath).
  4. Öffnen Sie die BlockIt-Erweiterung, fügen Sie den kopierten Selektor in das Eingabefeld ein, wählen Sie den Blockierungsmodus und klicken Sie auf "Regel hinzufügen".
  5. Fertig! Die Regel erscheint in der Liste der aktiven Regeln, und das Element verschwindet von der Seite.
  6. Um die Entwicklertools zu schließen, drücken Sie F12 oder klicken Sie auf das Kreuz in der oberen rechten Ecke des DevTools-Panels.

Was bedeuten die Blockierungsmodi?

  • Entfernen (geeignet für die meisten Fälle): Das Element wird vollständig aus dem HTML-Code der Seite entfernt, und sein Platz wird für andere Elemente freigegeben. Diese Option kann jedoch manchmal dazu führen, dass das Layout bricht.
  • Ausblenden: Das Element wird unsichtbar, nimmt aber weiterhin denselben Platz auf der Seite ein. Das Layout bricht nicht.

Erweiterte Funktionen Zum Seitenanfang

Blockierung mit XPath

XPath ist nützlich auf Websites, die dynamische Klassen (Verschleierung) verwenden, wenn CSS-Selektoren instabil sind.

So kopieren Sie XPath:

  1. Finden Sie das Element über "Untersuchen".
  2. Klicken Sie mit der rechten Maustaste auf das Element im Code → Kopieren → XPath kopieren (oder Copy XPath).
  3. Fügen Sie den kopierten Ausdruck in das Eingabefeld von BlockIt ein. Die Erweiterung erkennt automatisch, dass es sich um XPath handelt, und Sie müssen dafür nicht den erweiterten Modus aktivieren.

Erweiterter Modus

Im Basismodus bietet die Erweiterung ein einfaches Feld zur Eingabe eines Selektors. Für eine feinere Anpassung der Regeln und zusätzliche Werkzeuge gibt es den Erweiterten Modus. Um ihn zu aktivieren, klicken Sie auf die entsprechende Schaltfläche in der Oberfläche der Erweiterung.

In diesem Modus haben Sie Zugriff auf:

  • HTML-Parser: Fügen Sie den HTML-Code eines Elements ein, und die Erweiterung schlägt automatisch einen Selektor vor, der aus seinen Attributen zusammengesetzt ist.
  • Attributbearbeitung: Nach dem Parsen sehen Sie eine Liste der Attribute des Elements und können unzuverlässige (z.B. dynamisch generierte Klassen) entfernen, um den Selektor zu verfeinern.
  • Manuelle Attributergänzung: Sie können manuell ein Attribut und seinen Wert hinzufügen, wenn Sie den Selektor weiter verfeinern möchten.
  • Regeln exportieren und importieren: Teilen Sie Ihre Regeln mit anderen oder übertragen Sie sie zwischen Geräten.

HTML-Parser, Bearbeitung und Hinzufügen von Attributen

Diese drei Werkzeuge arbeiten zusammen als ein einheitlicher Workflow zum Erstellen präziser Selektoren, ohne sich die Syntax merken zu müssen:

  1. Kopieren Sie den HTML-Code des Elements (Rechtsklick → Kopieren → Element kopieren (oder Copy element)).
  2. Aktivieren Sie den erweiterten Modus in der Erweiterung und fügen Sie den HTML-Code in das entsprechende Feld ein. Klicken Sie auf "Analysieren". Die Erweiterung analysiert den Code und zeigt Ihnen das Tag und eine Liste aller seiner Attribute.
  3. Bearbeiten Sie die vorgeschlagene Attributliste. Behalten Sie nur die Attribute, die sich in Zukunft voraussichtlich nicht ändern werden. Zum Beispiel sind id und class, die wie dynamisch generierter Unsinn aussehen, dafür ungeeignet. Der Selektor im Eingabefeld wird automatisch bei jeder Änderung aktualisiert.
  4. Fügen Sie bei Bedarf manuell Attribute hinzu. Wenn der vorgeschlagene Satz von Attributen nicht ausreicht, um einen eindeutigen Selektor zu erstellen, können Sie eigene hinzufügen.
  5. Klicken Sie auf "Regel hinzufügen" und bestätigen Sie, dass sie hinzugefügt wurde und das Element von der Seite entfernt wurde.

Tipps zur Auswahl eines zu blockierenden Elements Zum Seitenanfang

Die folgenden Methoden sind von der einfachsten bis zur fortgeschrittensten geordnet. Beginnen Sie mit der ersten und gehen Sie zur nächsten über, wenn die vorherige nicht funktioniert.

1. Selektor aus DevTools kopieren

Dies ist die einfachste Methode, die für die meisten Websites funktioniert. Die Anweisungen finden Sie im Abschnitt "Wie blockiere ich ein Element".

2. XPath aus DevTools kopieren

Verwenden Sie diese Methode, wenn der kopierte Selektor aufgrund dynamischer Klassen auf der Website nicht funktioniert. Die Anweisungen zum Kopieren von XPath finden Sie im Abschnitt "Blockierung mit XPath".

3. HTML-Parser verwenden (im erweiterten Modus)

Diese Methode ist praktisch, wenn Sie die Theorie der Selektoren kennen, sich aber nicht an die genaue Syntax erinnern. Sie fügen den HTML-Code eines Elements ein, und die Erweiterung schlägt einen Selektor basierend auf seinen Attributen vor.

4. Attributliste bearbeiten (im erweiterten Modus)

Nach der Verwendung des HTML-Parsers sehen Sie eine Liste aller Attribute des Elements. Behalten Sie nur die Attribute, die sich in Zukunft voraussichtlich nicht ändern werden. Dynamisch generierte Klassen (Unsinn) sind dafür ungeeignet.

5. Attribute manuell hinzufügen (im erweiterten Modus)

Wenn keine der automatischen Methoden einen stabilen Selektor liefert, können Sie manuell ein eindeutiges Attribut und seinen Wert hinzufügen, um die Suche einzugrenzen.

6. Selektor manuell schreiben

Erfordert ein grundlegendes Verständnis der CSS-Selektor-Syntax. Dies gibt Ihnen mehr Kontrolle und Stabilität. Um die Grundlagen zu erlernen, lesen Sie den Spickzettel für Selektoren oder die CSS- und XPath-Selektor-Referenz (auf Russisch).

Regeln exportieren und importieren Zum Seitenanfang

Diese Funktion ermöglicht es Ihnen, Regeln mit anderen zu teilen oder zwischen Computern zu übertragen. Verfügbar im erweiterten Modus.

  • Exportieren: Speichert alle Ihre Regeln in einer JSON-Datei.
  • Importieren: Lädt Regeln aus einer JSON-Datei. Sie können alle aktuellen Regeln ersetzen oder neue hinzufügen (Duplikate werden übersprungen).

Wie importiere ich Regeln?

  • Klicken Sie im erweiterten Modus auf die Schaltfläche "Importieren", ein Fenster öffnet sich, klicken Sie auf "Datei auswählen" und wählen Sie die Datei.
  • Wählen Sie die Option: importierte Regeln zu Ihrer Liste hinzufügen oder Ihre Liste durch die importierten ersetzen. Je nachdem, was Sie möchten, klicken Sie auf "Alle ersetzen" oder "Hinzufügen".
  • Wenn alles erfolgreich war, sehen Sie eine Importbestätigung und die neuen Regeln erscheinen in Ihrer Liste der aktiven Regeln im Erweiterungsfenster.

Fehlerbehebung (FAQ) Zum Seitenanfang

Meine Regel hat nicht funktioniert

  • Möglicher Grund Nr. 1. Das ausgewählte Element ist nicht das äußerste: Versuchen Sie, im HTML-Baum nach oben zu gehen und einen Selektor für den übergeordneten Container zu kopieren.
  • Möglicher Grund Nr. 2. Die Website verwendet dynamische Klassen (Verschleierung): In diesem Fall kann der kopierte Selektor aufhören zu funktionieren. Verwenden Sie XPath oder schreiben Sie einen Selektor manuell.
  • Möglicher Grund Nr. 3. Das Element wird dynamisch geladen: Die Erweiterung wendet Regeln automatisch erneut an, wenn sich die Seite ändert. Wenn das nicht geholfen hat, versuchen Sie, die Seite zu aktualisieren.
  • Möglicher Grund Nr. 4. Die Regel wurde für eine andere Domain erstellt: Überprüfen Sie, ob sich die Regel in der Gruppe "Für diese Seite" oder "Für andere Seiten" befindet.

Der Selektor findet keine Elemente

  • Überprüfen Sie Ihren Selektor: Öffnen Sie DevTools (F12), wechseln Sie zum Tab "Elements", drücken Sie Ctrl+F (oder Cmd+F auf Mac) und geben Sie Ihren Selektor in das Suchfeld ein. Wenn die Suche nichts findet, ist Ihr Selektor falsch.
  • Die Seite verwendet Shadow DOM: In diesem Fall können Standardselektoren nicht funktionieren. Versuchen Sie, XPath zu verwenden oder das Element innerhalb der Shadow-Wurzel zu suchen.
  • Das Element wird nach der Skriptausführung geladen: Einige Elemente erscheinen mit Verzögerung. Versuchen Sie, die Seite zu aktualisieren oder zu warten.

Nach dem Entfernen eines Elements ist das Layout kaputt und sieht schlimmer aus als mit der Werbung

  • Lösung: Löschen Sie die Regel und erstellen Sie sie neu, aber wählen Sie den Modus "Ausblenden". Dies bewahrt den Platz auf der Seite und hält das Layout intakt.

Der Selektor findet zu viele Elemente

Verfeinern Sie den Selektor, indem Sie weitere Attribute hinzufügen oder einen spezifischeren Pfad verwenden. Im erweiterten Modus können Sie manuell ein eindeutiges Attribut hinzufügen, um die Suche einzugrenzen.

Nichts hilft

Wenn Sie alles versucht haben und das Element sich hartnäckig weigert, blockiert zu werden, ist vielleicht das Beste, was Sie tun können, diese Seite zu vergessen und sie zu verlassen. 😄

Spickzettel für Selektoren Zum Seitenanfang

Was sind Selektoren?

Selektoren sind eine Möglichkeit, ein bestimmtes Element auf einer Webseite anhand seiner Eigenschaften zu finden: Tag, Klasse, ID, Attribute oder Position in der HTML-Struktur.

Im Gegensatz zu CSS-Stilen, bei denen Selektoren zum Anwenden von Formatierungen verwendet werden, werden Selektoren in BlockIt nur zum Auffinden von Elementen verwendet. Wir setzen keine Farben, Schriften oder Abstände – wir finden einfach das Element, um es zu blockieren.

So öffnen Sie die Entwicklertools

Die Entwicklertools (DevTools) sind das Hauptwerkzeug für die Arbeit mit Selektoren. So öffnen Sie sie:

Aktion Ergebnis
Drücken Sie F12 Das DevTools-Panel öffnet sich
Oder drücken Sie Ctrl + Shift + I Dasselbe
Oder klicken Sie mit der rechten Maustaste auf ein Element → "Untersuchen" DevTools öffnet sich mit dem hervorgehobenen Element

So passen Sie die Entwicklertools an

Oberflächensprache

  1. Öffnen Sie DevTools (F12).
  2. Klicken Sie auf das Zahnradsymbol (⚙️) in der oberen rechten Ecke → Einstellungen.
  3. Wählen Sie im Abschnitt "Sprache" Ihre bevorzugte Sprache aus dem Dropdown-Menü.
  4. Schließen Sie DevTools und öffnen Sie es erneut.

Panel-Position

  1. Klicken Sie auf die drei Punkte (⋮) in der oberen rechten Ecke von DevTools.
  2. Wählen Sie eine der Optionen:
    • Dock to right (Standard)
    • Dock to bottom — praktisch, wenn Sie einen breiten Monitor haben
    • Dock to left — wenn Sie ein anderes Layout bevorzugen
    • Undock into separate window — verschieben Sie es auf einen anderen Monitor

So testen Sie Selektoren in den Entwicklertools

Der schnellste Weg, um zu überprüfen, ob Ihr Selektor funktioniert, ist die Suche (Ctrl + F):

  1. Öffnen Sie DevTools (F12) und gehen Sie zum Tab "Elements".
  2. Drücken Sie Ctrl + F (oder Cmd + F auf Mac).
  3. Geben Sie Ihren Selektor in das Suchfeld ein.
  4. DevTools hebt alle Elemente hervor, die dem Selektor entsprechen.

Die Suchleiste zeigt an, wie viele Elemente gefunden wurden (z.B. 1 of 3). Das hilft Ihnen zu verstehen, wie präzise Ihr Selektor ist.

Praktisches Beispiel: Katzen-Meme-Galerie

Wenden wir dieses Wissen nun in der Praxis an. Öffnen Sie die Seite example.html und öffnen Sie DevTools. Versuchen Sie, die Selektoren aus der folgenden Tabelle einzugeben und sehen Sie, welche Elemente sie finden.

Selektortypen

1. Universeller Selektor (*)

Findet alle Elemente auf der Seite. Mit Vorsicht zu verwenden – er gibt alles im HTML zurück.

Selektor: *

Was er findet: Alle Elemente ohne Ausnahme.

2. Typselektor

Findet alle Elemente mit dem angegebenen HTML-Tag.

Selektoren: h1, p, button, div

Was sie finden:

  • h1 — alle Überschriften der ersten Ebene
  • p — alle Absätze
  • button — alle Schaltflächen
  • div — alle <div>-Container

3. Klassenselektor (.Klasse)

Findet alle Elemente mit der angegebenen Klasse im class-Attribut.

Selektoren: .card, .card__title, .btn--view

Was sie finden:

  • .card — alle Elemente mit der Klasse card
  • .card__title — alle Elemente mit der Klasse card__title
  • .btn--view — alle Elemente mit der Klasse btn--view

4. ID-Selektor (#id)

Findet ein Element mit einer eindeutigen id. Es sollte nur ein solches Element auf der Seite geben.

Selektoren: #salad-cat, #confused-cat, #bread-cat

Was sie finden:

  • #salad-cat — das Element mit id="salad-cat"
  • #confused-cat — das Element mit id="confused-cat"
  • #bread-cat — das Element mit id="bread-cat"

5. Kombinierte Selektoren

Sie können Tag, Klasse und ID für eine präzisere Suche kombinieren.

Selektoren: h2.card__title, div.card, p.card__description, button.btn--edit

Was sie finden:

  • h2.card__title — <h2> mit der Klasse card__title
  • div.card — <div> mit der Klasse card
  • p.card__description — <p> mit der Klasse card__description
  • button.btn--edit — <button> mit der Klasse btn--edit

6. Attributselektor ([attribut="wert"])

Findet Elemente mit einem bestimmten Attribut und Wert.

Selektoren: [data-type="description"], [data-type="title"]

Was sie finden:

  • [data-type="description"] — alle Elemente mit data-type="description"
  • [data-type="title"] — Elemente mit data-type="title"

7. Nachfahre selektor (Leerzeichen)

Findet Elemente, die sich innerhalb eines anderen Elements befinden (auf jeder Verschachtelungsebene).

Selektor: .card .btn

Was er findet: Alle Elemente mit der Klasse btn, die sich innerhalb eines Elements mit der Klasse card befinden.

8. Direkter-Kind-Selektor (>)

Findet Elemente, die direkte Kinder eines anderen Elements sind. Die Suche geht nur eine Ebene tief.

Selektor: .card__body > .card__title

Was er findet: Elemente mit der Klasse card__title, die direkte Kinder eines Elements mit der Klasse card__body sind.

9. Angrenzender-Geschwister-Selektor (+)

Findet ein Element, das das nächste Geschwisterelement eines anderen Elements auf derselben Verschachtelungsebene ist.

Selektor: #confused-cat + .card__description

Was er findet: Den Absatz (<p>), der unmittelbar auf das Element mit id="confused-cat" folgt.

10. Positionspseudoklassen

Wählen Elemente basierend auf ihrer Position unter ihren Geschwistern aus.

Selektor: .card__actions :nth-child(2)

Was er findet: Das zweite Kindelement innerhalb des Elements mit der Klasse card__actions.

🔍 So überprüfen Sie Ihre Antworten

Nachdem Sie einen Selektor geschrieben haben, fügen Sie ihn in die Suchleiste von DevTools ein (Ctrl + F). Die Suchleiste zeigt an, wie viele Elemente gefunden wurden (z.B. 1 of 3).

  • Wenn Sie nach einem bestimmten einzelnen Element gesucht haben (z.B. nach id), sollte das Ergebnis 1 of 1 sein.
  • Wenn Sie nach einer Gruppe von Elementen gesucht haben (z.B. alle Absätze mit einer bestimmten Klasse), kann das Ergebnis 1 of 3 oder mehr sein – das ist normal.
  • Wichtig ist, dass die hervorgehobenen Elemente genau die sind, nach denen Sie gesucht haben. Überprüfen Sie visuell: Werden die richtigen Elemente auf der Seite hervorgehoben?

Wenn die falschen Elemente hervorgehoben werden, verfeinern Sie den Selektor, indem Sie weitere Bedingungen hinzufügen.
