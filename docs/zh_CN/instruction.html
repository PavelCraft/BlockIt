什么是 BlockIt？ 回到顶部

显示广告的网站和流行的广告拦截器之间存在着持续的“军备竞赛”：网站开发者不断寻找向您展示广告的新方法，而拦截器则不断寻找隐藏它们的方法。

BlockIt 提供了一种不同的方法。您无需依赖常见的过滤列表，而是自己创建规则来屏蔽特定元素。您的规则只有您自己知道（除非您决定分享），这使得它们更难被绕过。

主要功能：

  • 易于使用：只需从开发者工具中复制一个选择器，然后粘贴到扩展程序中即可。
  • 灵活性：
    • 支持 CSS 选择器和 XPath 表达式
    • 您自己决定是移除还是隐藏元素
    • 您自己决定屏蔽哪些元素，保留哪些
    • 您自己决定保留或删除哪些屏蔽规则
  • 隐私保护：所有规则都仅存储在您的浏览器本地，不会发送到任何地方。
  • 按网站分组规则：规则会自动针对当前网站和其他所有网站进行分组。这使得管理更加方便。
  • 分享设置：您可以通过将规则导出到文件来与其他用户分享您的规则。
  • 多语言支持：扩展程序界面会自动切换到您浏览器中设置的语言。支持的语言：俄语、英语、法语、德语、西班牙语、葡萄牙语、中文和日语。如果您的语言不受支持，界面将默认显示为英语。
  • 开源：该扩展程序遵循 BSD-3-Clause 许可证开发。您可以在 GitHub 上参与项目开发、提出改进建议并查看代码。

快速开始 回到顶部

安装

方法1（推荐）：前往 Chrome 网上应用店，找到 BlockIt 扩展程序，然后点击“安装”。安装后，请务必通过点击地址栏旁边的拼图图标并选择 BlockIt 旁边的“固定”来将扩展程序固定到浏览器工具栏。

方法 2（适用于开发者）：从 GitHub 下载源代码并加载未打包的扩展程序。

如何屏蔽一个元素

  1. 右键单击您要屏蔽的元素，然后选择“检查”（或“检查元素”）。此操作总是会直接将您带到 HTML 树中的该元素。
  2. 在 HTML 树中，找到您需要的元素。为了确保选择了正确的元素，请将鼠标悬停在代码行上——页面上的相应元素将被高亮显示。选择完全覆盖您要屏蔽的块的最外层元素。
  3. 右键单击树中的元素 → 复制 → 复制选择器（或 Copy selector）。对于 XPath：复制 XPath（或 Copy XPath）。
  4. 打开 BlockIt 扩展程序，将复制的选择器粘贴到输入字段中，选择屏蔽模式，然后点击“添加规则”。
  5. 完成！规则会出现在活动规则列表中，元素会从页面上消失。
  6. 要关闭开发者工具，请按 F12 或点击 DevTools 面板右上角的关闭按钮。

屏蔽模式是什么意思？

  • 移除（适用于大多数情况）：元素会完全从页面 HTML 中移除，其空间会被释放给其他元素。但是，此选项有时可能会导致布局错乱。
  • 隐藏：元素变为不可见，但继续在页面上占据相同的空间。布局不会错乱。

高级功能 回到顶部

使用 XPath 屏蔽

当 CSS 选择器不稳定时，XPath 在那些使用动态类（混淆）的网站上非常有用。

如何复制 XPath：

  1. 通过“检查”找到元素。
  2. 右键单击代码中的元素 → 复制 → 复制 XPath（或 Copy XPath）。
  3. 将复制好的表达式粘贴到 BlockIt 的输入字段中。扩展程序会自动识别出它是 XPath，并且您无需为此启用高级模式。

高级模式

在基本模式下，扩展程序提供一个简单的字段来输入选择器。为了更精细地调整规则和使用额外工具，还有高级模式。要启用它，请点击扩展程序界面中的相应按钮。

在此模式下，您可以访问：

  • HTML 解析器：粘贴元素的 HTML 代码，扩展程序会自动建议一个由该元素属性组成的选择器。
  • 属性编辑：解析后，您将看到元素属性列表，并可以移除不可靠的属性（例如，动态生成的类）来优化选择器。
  • 手动添加属性：如果您想进一步优化选择器，可以手动添加一个属性及其值。
  • 导出和导入规则：与其他用户分享您的规则，或在设备之间传输规则。

HTML 解析器、编辑和添加属性

这三个工具协同工作，形成一个统一的工作流程，用于在不记忆语法的情况下创建精确的选择器：

  1. 复制元素的 HTML 代码（右键单击 → 复制 → 复制元素（或 Copy element））。
  2. 在扩展程序中启用高级模式，并将 HTML 代码粘贴到相应的字段中。点击“解析”。扩展程序会解析代码，并向您显示标签及其所有属性的列表。
  3. 编辑建议的属性列表。只保留那些未来不太可能更改的属性。例如，看起来像动态生成的乱码的 id 和 class 并不适合此目的。输入字段中的选择器会在您每次进行更改时自动更新。
  4. 如有需要，手动添加属性。如果建议的属性集不足以创建唯一的选择器，您可以添加自己的属性。
  5. 点击“添加规则”，并确认它已被添加，且元素已从页面中移除。

选择要屏蔽的元素的技巧 回到顶部

以下方法按从最简单到最复杂的顺序排列。从第一个开始，如果前一个方法不起作用，再尝试下一个。

1. 从 DevTools 复制选择器

这是最简单的方法，适用于大多数网站。说明在 “如何屏蔽一个元素” 部分。

2. 从 DevTools 复制 XPath

如果由于网站上的动态类导致复制的选择器不起作用，请使用此方法。复制 XPath 的说明在 “使用 XPath 屏蔽” 部分。

3. 使用 HTML 解析器（在高级模式下）

如果您了解选择器理论，但不记得确切的语法，这种方法很实用。您粘贴元素的 HTML 代码，扩展程序会根据其属性建议一个选择器。

4. 编辑属性列表（在高级模式下）

使用 HTML 解析器后，您将看到元素的所有属性列表。只保留那些未来不太可能更改的属性。为此目的，动态生成的类（乱码）不是好选择。

5. 手动添加属性（在高级模式下）

如果自动方法都无法提供稳定的选择器，您可以手动添加一个唯一属性及其值来缩小搜索范围。

6. 手动编写选择器

需要对 CSS 选择器语法有基本的了解。这给您更多的控制和稳定性。要学习基础知识，请参阅 选择器速查表 或 CSS 和 XPath 选择器参考（俄语）。

导出和导入规则 回到顶部

此功能允许您与其他用户分享规则或在计算机之间传输规则。可在高级模式下使用。

  • 导出：将所有规则保存到一个 JSON 文件中。
  • 导入：从 JSON 文件加载规则。您可以替换所有当前规则或添加新规则（重复项将被跳过）。

如何导入规则？

  • 在高级模式下，点击“导入”按钮，将打开一个窗口，点击“选择文件”并选择文件。
  • 选择选项：将导入的规则添加到您的列表中，或用导入的规则替换您的列表。根据您的需要，点击“全部替换”或“添加”。
  • 如果一切顺利，您将看到一条确认信息，并且新规则将出现在扩展程序窗口的规则列表中。

问题排查（常见问题） 回到顶部

我的规则不起作用

  • 可能原因 #1. 选择的元素不是最外层的：尝试在 HTML 树中向上移动，为父容器复制一个选择器。
  • 可能原因 #2. 网站使用动态类（混淆）：在这种情况下，复制的选择器可能会失效。请使用 XPath 或手动编写选择器。
  • 可能原因 #3. 元素是动态加载的：当页面发生变化时，扩展程序会自动重新应用规则。如果这不起作用，请尝试刷新页面。
  • 可能原因 #4. 规则是为其他域名创建的：检查规则是否在“为此网站”或“为其他网站”组中。

选择器找不到任何元素

  • 检查您的选择器：打开 DevTools (F12)，转到“Elements”选项卡，按 Ctrl+F（Mac 上为 Cmd+F），然后在搜索框中输入您的选择器。如果搜索没有找到任何内容，则您的选择器不正确。
  • 页面使用了 Shadow DOM：在这种情况下，标准选择器可能无法工作。请尝试使用 XPath 或在影子根内部搜索元素。
  • 元素在脚本执行后加载：某些元素会延迟出现。请尝试刷新页面或等待。

移除元素后，布局错乱，看起来比有广告时更糟

  • 解决方案：删除该规则并重新创建，但选择“隐藏”模式。这样可以保留页面上的空间并保持布局完整。

选择器找到了太多元素

通过添加更多属性或使用更具体的路径来优化选择器。在高级模式下，您可以手动添加一个唯一属性来缩小搜索范围。

什么都不起作用

如果您已经尝试了所有方法，但该元素仍然顽固地拒绝被屏蔽，也许您能做的最好的事情就是忘记那个网站，然后离开它。😄

选择器速查表 回到顶部

什么是选择器？

选择器是一种根据其属性：标签、类、标识符、属性或 HTML 结构中的位置来查找网页上特定元素的方法。

与用于应用样式的 CSS 选择器不同，在 BlockIt 中，选择器仅用于查找元素。我们不会设置颜色、字体或边距——我们只是找到元素来屏蔽它。

如何打开开发者工具

开发者工具 (DevTools) 是使用选择器的主要工具。打开方法如下：

操作 结果
按 F12 打开 DevTools 面板
或按 Ctrl + Shift + I 相同
或右键单击元素 → “检查” 打开 DevTools 并高亮显示该元素

如何自定义开发者工具

界面语言

  1. 打开 DevTools (F12)。
  2. 点击右上角的齿轮图标 (⚙️) → 设置。
  3. 在“语言”部分，从下拉菜单中选择您偏好的语言。
  4. 关闭并重新打开 DevTools。

面板停靠位置

  1. 点击 DevTools 右上角的三个点 (⋮)。
  2. 选择以下选项之一：
    • 停靠到右侧（默认）
    • 停靠到底部 — 如果您的显示器较宽，这很方便
    • 停靠到左侧 — 如果您喜欢不同的布局
    • 取消停靠到单独窗口 — 将其移动到另一个显示器

如何在开发者工具中测试选择器

检查选择器是否有效的最快方法是使用搜索 (Ctrl + F)：

  1. 打开 DevTools (F12) 并转到 “Elements” 选项卡。
  2. 按 Ctrl + F（Mac 上为 Cmd + F）。
  3. 在搜索框中输入您的选择器。
  4. DevTools 将高亮显示所有匹配该选择器的元素。

搜索栏会显示找到了多少个元素（例如，1 of 3）。这有助于您了解选择器的精确度。

实践示例：猫表情包画廊

现在让我们将这些知识付诸实践。打开 example.html 页面 并打开 DevTools。尝试输入下表中的选择器，看看它们能找到哪些元素。

选择器类型

1. 通用选择器 (*)

查找页面上的所有元素。请谨慎使用——它会返回 HTML 中的所有内容。

选择器： *

查找内容：所有元素，无一例外。

2. 类型选择器

查找具有指定 HTML 标签的所有元素。

选择器： h1, p, button, div

查找内容：

  • h1 — 所有一级标题
  • p — 所有段落
  • button — 所有按钮
  • div — 所有 <div> 容器

3. 类选择器 (.class)

查找 class 属性中具有指定类的所有元素。

选择器： .card, .card__title, .btn--view

查找内容：

  • .card — 所有具有类 card 的元素
  • .card__title — 所有具有类 card__title 的元素
  • .btn--view — 所有具有类 btn--view 的元素

4. ID 选择器 (#id)

查找具有唯一 id 的元素。页面上应该只有一个这样的元素。

选择器： #salad-cat, #confused-cat, #bread-cat

查找内容：

  • #salad-cat — 具有 id="salad-cat" 的元素
  • #confused-cat — 具有 id="confused-cat" 的元素
  • #bread-cat — 具有 id="bread-cat" 的元素

5. 组合选择器

您可以组合标签、类和 ID 以进行更精确的搜索。

选择器： h2.card__title, div.card, p.card__description, button.btn--edit

查找内容：

  • h2.card__title — 具有类 card__title 的 <h2>
  • div.card — 具有类 card 的 <div>
  • p.card__description — 具有类 card__description 的 <p>
  • button.btn--edit — 具有类 btn--edit 的 <button>

6. 属性选择器 ([attribute="value"])

查找具有特定属性和值的元素。

选择器： [data-type="description"], [data-type="title"]

查找内容：

  • [data-type="description"] — 所有具有 data-type="description" 的元素
  • [data-type="title"] — 具有 data-type="title" 的元素

7. 后代选择器（空格）

查找位于另一个元素内部的元素（在任何嵌套级别）。

选择器： .card .btn

查找内容：所有具有类 btn 且位于具有类 card 的元素内部的元素。

8. 子元素选择器 (>)

查找作为另一个元素的直接子元素的元素。搜索仅深入一层。

选择器： .card__body > .card__title

查找内容：具有类 card__title 且是类 card__body 元素的直接子元素的元素。

9. 相邻兄弟选择器 (+)

查找在同一嵌套级别上作为另一个元素的下一个兄弟的元素。

选择器： #confused-cat + .card__description

查找内容：紧跟在具有 id="confused-cat" 的元素之后的段落 (<p>)。

10. 位置伪类

根据元素在其兄弟元素中的位置进行选择。

选择器： .card__actions :nth-child(2)

查找内容：具有类 card__actions 的元素内的第二个子元素。

🔍 如何检查您的答案

编写好选择器后，将其粘贴到 DevTools 的搜索栏中 (Ctrl + F)。搜索栏会显示找到了多少个元素（例如，1 of 3）。

  • 如果您在查找单个特定元素（例如，通过 id），结果应为 1 of 1。
  • 如果您在查找一组元素（例如，所有具有特定类的段落），结果可能为 1 of 3 或更多——这是正常的。
  • 最重要的是，高亮显示的元素正是您要查找的元素。请视觉检查：页面上是否正确高亮显示了元素？

如果高亮显示了错误的元素，请通过添加更多条件来优化选择器。
