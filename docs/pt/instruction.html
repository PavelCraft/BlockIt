O que é o BlockIt?

Sites com publicidade e bloqueadores populares vivem numa corrida constante: os programadores dos sites procuram contornar listas públicas de filtros e os dos bloqueadores atualizam-nas continuamente.

BlockIt adota outra abordagem para bloquear anúncios e outros elementos indesejados. Em vez de depender apenas de listas partilhadas, cria regras para elementos concretos dos sites que utiliza. Enquanto não partilhar essas regras, o site desconhece as características em que se baseiam e tem mais dificuldade em anulá-las deliberadamente.

Principais funcionalidades

  • Facilidade de utilização: não precisa de memorizar a sintaxe de CSS, XPath ou das regras BlockIt. Por vezes basta copiar um seletor do DevTools e colá-lo na extensão.
  • Flexibilidade:
    • Decide se pretende remover ou ocultar um elemento
    • Decide quais os elementos a bloquear e a manter
    • Decide quais as regras a manter, desativar ou eliminar
    • São suportados seletores CSS e expressões XPath
    • As regras também se aplicam dentro de iframes e Shadow DOM
  • Privacidade: todas as regras são guardadas localmente no navegador e não são enviadas.
  • Sintaxe BlockIt: casos complexos podem usar uma sintaxe que amplia o CSS normal. Consulte, se necessário, a documentação da sintaxe BlockIt.
  • Agrupamento por site: as regras são agrupadas automaticamente para o site atual e os restantes.
  • Partilha de definições: exporte as regras para um ficheiro.
  • Vários idiomas: a extensão segue o idioma do navegador. Suporta russo, inglês, francês, alemão, espanhol, português, chinês e japonês. Na ausência do seu idioma, usa inglês.
  • Código aberto: a extensão é desenvolvida sob a licença BSD-3-Clause. Pode contribuir, propor melhorias e consultar o código no GitHub.

Dicas para escolher o elemento a bloquear

Antes de copiar um seletor ou HTML, determine exatamente qual elemento pretende bloquear.

  • Use o realce do DevTools. Passe sobre as linhas HTML para ver os elementos correspondentes e a área que será bloqueada.
  • Escolha o elemento mais exterior sem incluir conteúdo extra. Um elemento demasiado profundo pode deixar publicidade visível; um demasiado amplo pode ocultar conteúdo útil.
  • Observe o número de elementos. Uma correspondência costuma ser mais segura. Várias são adequadas se verificou todas; 0 significa que nada será encontrado.

Se a regra bloquear demasiado ou nada, elimine-a e escolha outro elemento acima ou abaixo na árvore HTML.

Modos de bloqueio

  • Remover: remove o elemento do HTML e liberta o espaço. Pode alterar a disposição.
  • Ocultar: torna-o invisível, mas mantém o espaço. Use se a remoção piorar a página.

Formas de criar uma regra Voltar ao início

Primeiro encontre o elemento no DevTools e examine a etiqueta, as classes e os atributos.

O que pode ajudar?

Ative as sugestões relevantes. O realce não oculta os outros métodos; apenas indica um ponto de partida.

Os métodos recomendados são realçados abaixo. Selecione um para ler as instruções.

1Copiar um seletor CSS do DevTools Selecione para ler

Comece aqui para testar rapidamente um seletor normal. O DevTools cria-o: selecione o elemento e escolha «Copiar» / “Copy” → «Copiar selector» / “Copy selector”.

Cole-o no BlockIt, verifique as correspondências e adicione a regra. Se deixar de ser fiável, use StableHTMLFinder ou o construtor.

1
2Copiar XPath do DevTools Selecione para ler

XPath descreve um caminho até ao elemento. Pode ajudar quando os atributos são instáveis, mas o caminho permanece igual. Escolha «Copiar XPath» / “Copy XPath” e cole a expressão no BlockIt.

Examine a expressão copiada. O Chrome pode criar XPath em torno de um id. Se o ID mudar, XPath também será instável. Um caminho absoluto deixa de funcionar quando a estrutura muda.

O BlockIt avalia XPath separadamente no documento principal e em cada iframe, por isso um XPath copiado num iframe pode funcionar. Os navegadores não o avaliam através do Shadow DOM. Nesse caso, use o construtor ou o StableHTMLFinder.

1
3Criar uma regra rápida a partir de HTML Selecione para ler

Este método oferece mais controlo: após analisar o HTML, escolhe os atributos incluídos.

1
Não mantenha automaticamente todos os atributos. Uma classe ou ID de aspeto aleatório pode mudar no carregamento seguinte.
4Usar o StableHTMLFinder Selecione para ler

StableHTMLFinder ajuda quando classes e IDs são ofuscados, mudam entre carregamentos ou existem muitos blocos semelhantes. É mais simples que examinar o HTML, mas a análise leva tempo.

1

StableHTMLFinder não bloqueia elementos. Ajuda a escolher a base da regra BlockIt:

  • Seletor CSS: a opção mais simples quando usa características estáveis e encontra o número correto.
  • Regra BlockIt: quando uma correspondência precisa exige sintaxe ampliada.
  • Examinar o mapa: estude as características estáveis e o ambiente e introduza-as no construtor quando o resultado gerado não for preciso.
5Abrir o construtor de regras Selecione para ler

O construtor cria regras precisas sem conhecer CSS, XPath ou BlockIt. Funciona com elementos estáveis e instáveis e pode usar texto, quantidade de atributos ou classes, posição entre irmãos e elementos circundantes.

Copie o HTML no DevTools, abra o «Modo avançado», cole-o no campo e clique em «Abrir construtor de regras».

Cartão do elemento

Cada cartão descreve um elemento HTML: etiqueta, quantidade de atributos e condições de atributos, texto e posição.

Árvore de relações

Os antepassados aparecem acima, os descendentes abaixo com avanço e os irmãos no mesmo nível.

Características estáveis

Pode desativar valores inseridos automaticamente. Não use IDs e classes variáveis apenas porque surgem no HTML.

Verificação

Verifique as correspondências e use «Verificar após atualizar» para confirmar a estabilidade.

Condições disponíveis num cartão

  • Etiqueta: indique-a ou deixe em branco se não for importante.
  • Quantidade de atributos: exatamente, pelo menos ou no máximo o número indicado.
  • Atributos: condições para nomes e valores; em class, também a quantidade de classes.
  • Texto: texto próprio ou todo o texto interior; correspondência exata, prefixo, sufixo, fragmento ou expressão regular.
  • Posição entre irmãos: posição entre os filhos do mesmo pai.

Elementos relacionados

Pode adicionar um pai direto ou qualquer antepassado ao alvo e aos seus antepassados. O alvo também pode ter filho, descendente ou irmão. Os elementos relacionados têm a opção «Pode estar ausente».

Posição entre irmãos é o lugar entre os filhos de um pai. Posição nos resultados é o lugar entre todos os elementos encontrados pela regra. São condições diferentes.

Pré-visualização e verificação

Leia a descrição em «Pré-visualização da regra». Ajuda a detetar atributos, texto ou relações incluídos por engano. Verifique depois as correspondências antes e após atualizar.

Exemplo: uma regra para vários elementos

  1. Ative «Posição entre irmãos» e indique 2, 3 e 5 neste exemplo.
  2. Mantenha a correspondência exata para o nome class.
  3. Remova a parte pouco fiável do valor e altere «valor: exatamente» para «valor: contém».
  4. Desative «Quantidade de classes» se puder mudar.
  5. Leia a pré-visualização e confirme que todas as condições são necessárias.
  6. Feche o DevTools na página e clique em «Verificar após atualizar».
  7. Confirme que o número de correspondências não muda.
  8. Clique em «Criar regra».

Quando mudar de método

Comece com um seletor CSS do DevTools. Uma regra rápida é útil se as características forem estáveis, mas quiser controlar os atributos. Se forem instáveis ou houver muitos blocos semelhantes, use StableHTMLFinder ou o construtor.

Resumo de seletores CSS Voltar ao início

O que são seletores?

Os seletores encontram um elemento pelas propriedades: etiqueta, classe, identificador, atributos ou posição no HTML.

Nos estilos CSS, aplicam formatação. No BlockIt servem apenas para encontrar elementos e bloqueá-los.

Estes exemplos ajudam a ler e editar seletores CSS comuns.

Como verificar um seletor

  1. Abra o separador «Elementos» / “Elements” no DevTools.
  2. Prima Ctrl + F ou Cmd + F no Mac.
  3. Cole o seletor na pesquisa.
  4. O DevTools realça as correspondências e mostra a quantidade, por exemplo 1 of 3.
1

Tipos de seletores

Seletor universal (*)

Encontra todos os elementos. Use com cuidado.

Seletor: *

O que encontra: todos os elementos, sem exceção.

Seletor por etiqueta

Encontra todos os elementos com a etiqueta indicada.

Seletores: h1, p, button, div

O que encontram:

  • h1 — todos os títulos de primeiro nível;
  • p — todos os parágrafos;
  • button — todos os botões;
  • div — todos os contentores <div>.

Seletor por classe (.class)

Encontra elementos com a classe indicada. Escreva várias classes juntas, sem espaços.

Seletores: .card, .card__title, .card.featured

O que encontram:

  • .card — todos os elementos da classe card;
  • .card__title — todos os elementos da classe card__title;
  • .card.featured — elementos com ambas as classes, card e featured.

Um elemento pode ter outras classes: class="card featured compact" também corresponde a .card.featured. Para exigir exatamente a lista completa, use [class="card featured"]; esta forma depende da ordem e não permite classes adicionais.

Seletor por identificador (#id)

Encontra o elemento com o id único indicado.

Seletores: #salad-cat, #confused-cat, #bread-cat

O que encontram:

  • #salad-cat — o elemento com id="salad-cat";
  • #confused-cat — o elemento com id="confused-cat";
  • #bread-cat — o elemento com id="bread-cat".

Seletor por atributo ([attribute="value"])

Pode verificar um valor exato ou apenas a presença do atributo. Escreva várias condições juntas.

Seletores: [data-type], [data-type="description"], [data-type="description"][aria-label="Card"], [class~="card"], [class="card featured"]

O que encontram:

  • [data-type] — elementos que têm data-type, seja qual for o valor;
  • [data-type="description"] — elementos cujo data-type é exatamente description;
  • [data-type="description"][aria-label="Card"] — elementos em que ambos os atributos correspondem;
  • [class~="card"] — elementos cuja lista de classes contém a classe separada card;
  • [class="card featured"] — elementos cujo atributo class completo é exatamente o texto indicado.
Formas de comparar um valor
[href^="https://"]
o valor começa por https://
[src$=".png"]
o valor termina em .png
[class*="advert"]
o valor contém advert em qualquer posição
[class~="card"]
a lista de palavras separadas por espaços inclui card
[lang|="en"]
o valor é en ou começa por en-, como en-US
[aria-label*="advertisement" i]
o valor contém advertisement, ignorando maiúsculas e minúsculas

Um seletor verifica apenas os atributos indicados, sem proibir outros. Por exemplo, [data-type="description"][aria-label="Card"] também encontra <div data-type="description" aria-label="Card" title="Details">: o atributo title adicional não impede a correspondência. O CSS normal não consegue exigir a ausência de todos os outros atributos.

Seletores combinados

Etiqueta, classe, ID e atributos podem ser combinados sem espaços para o mesmo elemento.

Seletores: h2.card__title, div.card.featured, div[data-type="description"], article.card[data-type="advertisement"][aria-label="Advertisement"]

O que encontram:

  • h2.card__title — um <h2> da classe card__title;
  • div.card.featured — um <div> com as duas classes; outras classes são permitidas;
  • div[data-type="description"] — um <div> com o atributo indicado; outros atributos são permitidos;
  • article.card[data-type="advertisement"][aria-label="Advertisement"] — um <article> da classe card cujos dois atributos têm exatamente os valores indicados.

Seletor de descendente (espaço)

Encontra elementos dentro de outro em qualquer nível.

Seletor: .card .btn

O que encontra: todos os elementos da classe btn dentro de um elemento da classe card.

Seletor de filho (>)

Encontra filhos diretos de outro elemento.

Seletor: .card__body > .card__title

O que encontra: elementos da classe card__title que são filhos diretos de um elemento da classe card__body.

Seletor de irmão adjacente (+)

Encontra o irmão seguinte no mesmo nível.

Seletor: #confused-cat + .card__description

O que encontra: o elemento da classe card__description imediatamente após o de id="confused-cat".

Pseudoclasse de posição

Seleciona elementos pela posição entre irmãos.

Seletor: .card__actions :nth-child(2)

O que encontra: o segundo filho dentro de um elemento da classe card__actions.

Os seletores CSS normais têm limitações. Não conseguem indicar a quantidade de atributos ou classes sem os enumerar, o texto próprio ou interior, expressões regulares ou padrões para nomes de atributos. Por exemplo, [data-*] não é CSS normal. Para estes casos existem regras BlockIt, que estendem a sintaxe CSS com [data-*], :attr-name(/^data-/) e outras condições. Consultar a documentação da sintaxe BlockIt.

O que são iframe e Shadow DOM? Voltar ao início

iframe é uma página independente incorporada noutra. O conteúdo pertence a um documento próprio, por isso uma pesquisa normal na página principal não entra diretamente nele.

Exemplo de iframe em HTML 
<main>
  <h1>Página principal</h1>
  <iframe src="advertisement.html"></iframe>
</main>

O conteúdo de advertisement.html carrega como documento separado dentro do <iframe>.

Shadow DOM é a árvore interna isolada de um componente. Permite separar o seu HTML do resto da página; uma raiz fechada também a oculta dos scripts normais.

Exemplo de Shadow DOM no DevTools 
<video-player>
  #shadow-root (open)
    <button class="play">Reproduzir</button>
</video-player>

O botão pertence à raiz shadow de <video-player>, não à árvore normal da página.

Estas estruturas criam limites de pesquisa: a regra precisa de funcionar no documento principal, em cada iframe acessível e nas raízes shadow. Nem todos os bloqueadores o fazem. O BlockIt aplica seletores CSS e regras estendidas em iframe e Shadow DOM; XPath funciona apenas em documentos e não atravessa uma fronteira Shadow DOM.

Gestão de regras Voltar ao início

As regras aparecem na lista do site atual ou na lista sem domínio. As regras do construtor podem ser editadas ou eliminadas; as desativadas permanecem assinaladas.

Desativar e eliminar

Como desativar uma regra?

Encontre-a em «Regras ativas» e clique em «Desativar». Permanece marcada, mas deixa de ser aplicada. Atualize a página para restaurar um elemento já removido.

Como eliminar uma regra?

Encontre-a em «Regras ativas» e clique em «Eliminar». Atualize a página com F5 para restaurar o elemento.

Exportar e importar

A exportação guarda as regras num ficheiro. A importação adiciona-as ou substitui a lista atual, permitindo transferir definições.

1

Verificar regras

Abra a página e depois o BlockIt. Em «Para este site: <domínio>», clique em «Verificar regras».

A verificação mostra se as regras encontram elementos. Pode medir uma vez ou ativar «Verificar estabilidade» com vários carregamentos. O BlockIt suspende temporariamente as regras e mostra as correspondências em cada carregamento.

  • Funciona: encontra sempre o mesmo número, diferente de zero.
  • Instável: o número muda entre carregamentos.
  • Não funcionou: nenhuma correspondência.
  • Erro: não foi possível executar a regra.

São verificadas as regras do domínio base atual e as regras sem domínio. O BlockIt não separa subdomínios: uma regra de e.mail.ru é guardada para mail.ru. Contudo, a verificação usa a página exata onde abriu o diagnóstico. Para um resultado fiável, abra a página para a qual criou a regra.

A verificação mede correspondências, não a finalidade dos elementos. Um resultado diferente de zero não garante que encontrou apenas o que pretendia bloquear.

Resolução de problemas Voltar ao início

Foi bloqueado algo além da publicidade

Isso acontece quando o seletor é demasiado abrangente e encontra também outros elementos da página.

O que fazer:

  • Elimine a regra como explicado em «Gestão de regras».
  • Escolha um elemento mais preciso: suba ou desça na árvore HTML até encontrar um contentor que inclua apenas a publicidade.
  • Verifique o número de correspondências antes de adicionar a regra. Várias só são aceitáveis quando todas devem ser bloqueadas.
A regra não funcionou
  • Causa possível 1: não foi selecionado o elemento exterior. Suba na árvore HTML e copie o seletor do contentor principal.
  • Causa possível 2: o site usa classes dinâmicas (ofuscação). Um seletor copiado pode deixar de funcionar após atualizar. Em «Formas de criar uma regra», assinale que as características são instáveis e tente um método sugerido, como StableHTMLFinder ou o construtor.
  • Causa possível 3: a estrutura da página mudou após criar a regra. Verifique o HTML atual e a quantidade de correspondências. Se o site reconstruiu o bloco, volte a copiar o seletor ou refine a regra no construtor.
  • Causa possível 4: a regra foi criada para outro domínio. Veja se está em «Para este site» ou «Para outros sites».
O seletor não encontra elementos
  • Verifique o seletor: abra o DevTools (F12), entre em «Elementos» / “Elements”, prima Ctrl + F (ou Cmd + F no Mac) e escreva o seletor. Se nada for encontrado, o seletor está incorreto.
O aspeto da página piorou após remover um elemento
  • Solução: elimine a regra e crie-a novamente no modo «Ocultar». Assim o espaço do elemento é mantido e o esquema da página não é alterado.
O seletor encontra elementos a mais

Verifique primeiro a quantidade e quais são os elementos. Se o alvo tiver uma classe ou atributo estável, acrescente-o ao seletor. Se não bastar, abra o construtor: ele pode usar texto, quantidade de classes e atributos, posição entre irmãos e relações com elementos próximos. Verifique a regra atualizada na página e após recarregar.

Não consigo compreender a estrutura HTML da página

Use StableHTMLFinder: compara vários carregamentos e cria um mapa de estabilidade. Procure o elemento no mapa e examine as suas características estáveis e os elementos próximos.

Se o HTML estiver muito ofuscado, o site poderá mostrar outra versão a quem usa VPN. Se for apropriado, desative temporariamente a VPN, recarregue e repita a análise. Não ajuda em todos os sites, mas permite verificar se a complexidade depende da versão recebida pela sua ligação.

Nada ajuda

Combine as características estáveis encontradas pelo StableHTMLFinder com o construtor do BlockIt. Assim pode criar manualmente uma regra que considere o elemento e o seu contexto.

Se já tentou vários métodos e a regra continua sem funcionar ou a extensão apresenta erros, envie uma mensagem pelo formulário de contacto do BlockIt. Inclua o URL da página, a regra e, se possível, capturas de ecrã.
