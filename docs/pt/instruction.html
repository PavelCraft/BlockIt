O que é o BlockIt? Voltar ao topo

Os sites que mostram anúncios e os bloqueadores de anúncios populares estão numa constante "corrida armamentista": os programadores de sites encontram continuamente novas formas de lhe mostrar anúncios, e os bloqueadores encontram formas de os ocultar.

O BlockIt oferece uma abordagem diferente. Em vez de depender de listas de filtros comuns, você cria as suas próprias regras para bloquear elementos específicos. As suas regras permanecem conhecidas apenas por si, a menos que decida partilhá-las, o que as torna muito mais resistentes a serem contornadas.

Principais funcionalidades:

  • Facilidade de utilização: Basta copiar um seletor das ferramentas de desenvolvimento e colá-lo na extensão.
  • Flexibilidade:
    • Suporta seletores CSS e expressões XPath
    • Você decide se elimina ou oculta um elemento
    • Você decide quais elementos bloquear e quais manter
    • Você decide quais regras de bloqueio manter e quais eliminar
  • Privacidade: Todas as regras são armazenadas localmente no seu navegador e não são enviadas para lado nenhum.
  • Agrupamento de regras por site: As regras são agrupadas automaticamente para o site atual e para todos os outros. Isto facilita a sua gestão.
  • Partilha de configurações: Pode partilhar as suas regras com outros utilizadores, exportando-as para um ficheiro.
  • Suporte multilíngue: A interface da extensão muda automaticamente para o idioma definido no seu navegador. Idiomas suportados: russo, inglês, francês, alemão, espanhol, português, chinês e japonês. Se o seu idioma não for suportado, a interface será exibida em inglês (idioma padrão).
  • Código aberto: A extensão é desenvolvida sob a licença BSD-3-Clause. Pode participar no desenvolvimento do projeto, sugerir melhorias e explorar o código no GitHub.

Início rápido Voltar ao topo

Instalação

Método 1 (recomendado): Vá para a Chrome Web Store, encontre a extensão BlockIt e clique em "Instalar". Após a instalação, certifique-se de fixar a extensão na barra de ferramentas do navegador clicando no ícone de puzzle ao lado da barra de endereços e selecionando "Fixar" junto ao BlockIt.

Método 2 (para desenvolvedores): Baixe o código fonte do GitHub e carregue a extensão descompactada.

Como bloquear um elemento

  1. Clique com o botão direito no elemento que deseja bloquear e selecione "Inspecionar" (ou "Inspecionar elemento"). Esta ação leva-o sempre diretamente ao elemento na árvore HTML.
  2. Na árvore HTML, encontre o elemento pretendido. Para ter a certeza de que selecionou o elemento correto, passe o cursor sobre as linhas de código — os elementos correspondentes na página serão realçados. Escolha o elemento mais externo que cobre completamente o bloco que deseja bloquear.
  3. Clique com o botão direito no elemento na árvore → Copiar → Copiar seletor (ou Copy selector). Para XPath: Copiar XPath (ou Copy XPath).
  4. Abra a extensão BlockIt, cole o seletor copiado no campo de entrada, escolha o modo de bloqueio e clique em "Adicionar regra".
  5. Pronto! A regra aparece na lista de regras ativas e o elemento desaparece da página.
  6. Para fechar as ferramentas de desenvolvimento, prima F12 ou clique na cruz no canto superior direito do painel DevTools.

O que significam os modos de bloqueio?

  • Eliminar (adequado para a maioria dos casos): O elemento é completamente removido do código HTML da página, libertando espaço para outros elementos. No entanto, esta opção pode, por vezes, fazer com que o layout se desfaça.
  • Ocultar: O elemento torna-se invisível, mas continua a ocupar o mesmo espaço na página. O layout não se desfaz.

Funcionalidades avançadas Voltar ao topo

Bloqueio com XPath

O XPath é útil em sites que utilizam classes dinâmicas (ofuscação) quando os seletores CSS são instáveis.

Como copiar XPath:

  1. Encontre o elemento através de "Inspecionar".
  2. Clique com o botão direito no elemento no código → Copiar → Copiar XPath (ou Copy XPath).
  3. Cole a expressão copiada no campo de entrada do BlockIt. A extensão reconhecerá automaticamente que é XPath e não precisa de ativar o modo Avançado para isso.

Modo Avançado

No modo básico, a extensão oferece um campo simples para inserir um seletor. Para um ajuste mais fino das regras e ferramentas adicionais, existe o Modo Avançado. Para o ativar, clique no botão correspondente na interface da extensão.

Neste modo, tem acesso a:

  • Analisador HTML: Cole o código HTML de um elemento e a extensão sugerirá automaticamente um seletor composto pelos seus atributos.
  • Edição de atributos: Após a análise, verá uma lista dos atributos do elemento e poderá remover os pouco fiáveis (por exemplo, classes geradas dinamicamente) para refinar o seletor.
  • Adição manual de atributos: Pode adicionar manualmente um atributo e o seu valor se pretender refinar ainda mais o seletor.
  • Exportar e importar regras: Partilhe as suas regras com outros ou transfira-as entre dispositivos.

Analisador HTML, edição e adição de atributos

Estas três ferramentas funcionam em conjunto como um fluxo de trabalho unificado para criar seletores precisos sem necessidade de memorizar a sintaxe:

  1. Copie o código HTML do elemento (Clique direito → Copiar → Copiar elemento (ou Copy element)).
  2. Ative o modo Avançado na extensão e cole o código HTML no campo correspondente. Clique em "Analisar". A extensão analisará o código e mostrar-lhe-á a tag e uma lista de todos os seus atributos.
  3. Edite a lista de atributos sugeridos. Mantenha apenas os atributos que têm menos probabilidades de mudar no futuro. Por exemplo, id e class que parecem texto gerado dinamicamente não são adequados para este fim. O seletor no campo de entrada será atualizado automaticamente com cada alteração que fizer.
  4. Adicione atributos manualmente se necessário. Se o conjunto de atributos sugerido não for suficiente para criar um seletor único, pode adicionar os seus próprios.
  5. Clique em "Adicionar regra" e confirme que foi adicionada e que o elemento foi removido da página.

Dicas para escolher um elemento para bloquear Voltar ao topo

Os métodos abaixo estão classificados do mais simples ao mais avançado. Comece pelo primeiro e passe para o seguinte se o anterior não funcionar.

1. Copiar o seletor do DevTools

Este é o método mais simples que funciona para a maioria dos sites. As instruções estão descritas na secção "Como bloquear um elemento".

2. Copiar XPath do DevTools

Utilize este método se o seletor copiado não funcionar devido a classes dinâmicas no site. As instruções para copiar XPath encontram-se na secção "Bloqueio com XPath".

3. Utilizar o analisador HTML (no modo Avançado)

Este método é prático se conhecer a teoria dos seletores, mas não se lembrar da sintaxe exata. Cola o código HTML de um elemento e a extensão sugere um seletor com base nos seus atributos.

4. Editar a lista de atributos (no modo Avançado)

Após utilizar o analisador HTML, verá uma lista de todos os atributos do elemento. Mantenha apenas aqueles que têm menos probabilidades de mudar no futuro. As classes geradas dinamicamente (texto sem sentido) não são adequadas para este fim.

5. Adicionar atributos manualmente (no modo Avançado)

Se nenhum dos métodos automáticos fornecer um seletor estável, pode adicionar manualmente um atributo único e o seu valor para limitar a pesquisa.

6. Escrever um seletor manualmente

Requer uma compreensão básica da sintaxe dos seletores CSS. Isto dá-lhe mais controlo e estabilidade. Para aprender o básico, consulte a Folha de referência de seletores ou a Referência de seletores CSS e XPath (em russo).

Exportar e importar regras Voltar ao topo

Esta funcionalidade permite-lhe partilhar regras com outros ou transferi-las entre computadores. Disponível no modo Avançado.

  • Exportar: Guarda todas as suas regras num ficheiro JSON.
  • Importar: Carrega regras de um ficheiro JSON. Pode substituir todas as regras atuais ou adicionar novas (os duplicados serão ignorados).

Como importar regras?

  • No modo Avançado, clique no botão "Importar", abrir-se-á uma janela, clique em "Escolher ficheiro" e selecione o ficheiro.
  • Escolha a opção: adicionar as regras importadas à sua lista ou substituir a sua lista pelas regras importadas. Dependendo do que pretende, clique em "Substituir tudo" ou "Adicionar".
  • Se tudo correu bem, verá uma mensagem de confirmação e as novas regras aparecerão na sua lista de regras ativas na janela da extensão.

Resolução de problemas (FAQ) Voltar ao topo

A minha regra não funcionou

  • Possível razão n.º 1. O elemento escolhido não é o mais externo: Tente subir na árvore HTML e copiar um seletor para o contentor principal.
  • Possível razão n.º 2. O site utiliza classes dinâmicas (ofuscação): Neste caso, o seletor copiado pode deixar de funcionar. Utilize XPath ou escreva um seletor manualmente.
  • Possível razão n.º 3. O elemento é carregado dinamicamente: A extensão reaplica as regras automaticamente quando a página muda. Se isso não ajudar, tente atualizar a página.
  • Possível razão n.º 4. A regra foi criada para um domínio diferente: Verifique se a regra está no grupo "Para este site" ou "Para outros sites".

O seletor não encontra nenhum elemento

  • Verifique o seu seletor: Abra o DevTools (F12), vá para o separador "Elements", prima Ctrl+F (ou Cmd+F no Mac) e introduza o seu seletor na caixa de pesquisa. Se a pesquisa não encontrar nada, o seu seletor está incorreto.
  • A página utiliza Shadow DOM: Neste caso, os seletores padrão podem não funcionar. Tente usar XPath ou procurar o elemento dentro da raiz sombra.
  • O elemento é carregado após a execução do script: Alguns elementos aparecem com atraso. Tente atualizar a página ou esperar.

Após eliminar um elemento, o layout desfez-se e parece pior do que com o anúncio

  • Solução: Elimine a regra e recrie-a, mas selecione o modo "Ocultar". Isto preserva o espaço na página e mantém o layout intacto.

O seletor encontra demasiados elementos

Refine o seletor adicionando mais atributos ou utilizando um caminho mais específico. No modo Avançado, pode adicionar manualmente um atributo único para limitar a pesquisa.

Nada funciona

Se já tentou tudo e o elemento se recusa obstinadamente a ser bloqueado, talvez o melhor que possa fazer seja esquecer esse site e abandoná-lo. 😄

Folha de referência de seletores Voltar ao topo

O que são seletores?

Os seletores são uma forma de encontrar um elemento específico numa página web pelas suas propriedades: tag, classe, identificador, atributos ou posição na estrutura HTML.

Ao contrário dos estilos CSS, onde os seletores são utilizados para aplicar formatação, no BlockIt os seletores são utilizados apenas para encontrar elementos. Não definimos cores, fontes ou margens — simplesmente encontramos o elemento para o bloquear.

Como abrir as ferramentas de desenvolvimento

As ferramentas de desenvolvimento (DevTools) são a principal ferramenta para trabalhar com seletores. Eis como as abrir:

Ação Resultado
Prima F12 O painel DevTools abre
Ou prima Ctrl + Shift + I O mesmo
Ou clique com o botão direito num elemento → "Inspecionar" O DevTools abre com o elemento realçado

Como personalizar as ferramentas de desenvolvimento

Idioma da interface

  1. Abra o DevTools (F12).
  2. Clique no ícone de engrenagem (⚙️) no canto superior direito → Configurações.
  3. Na secção "Idioma", selecione o seu idioma preferido no menu suspenso.
  4. Feche e reabra o DevTools.

Posição do painel

  1. Clique nos três pontos (⋮) no canto superior direito do DevTools.
  2. Escolha uma das opções:
    • Dock to right (padrão)
    • Dock to bottom — conveniente se tiver um monitor largo
    • Dock to left — se preferir uma disposição diferente
    • Undock into separate window — mova-o para outro monitor

Como testar seletores nas ferramentas de desenvolvimento

A forma mais rápida de verificar se o seu seletor funciona é usar a pesquisa (Ctrl + F):

  1. Abra o DevTools (F12) e vá para o separador "Elements".
  2. Prima Ctrl + F (ou Cmd + F no Mac).
  3. Introduza o seu seletor na caixa de pesquisa.
  4. O DevTools realçará todos os elementos que correspondem ao seletor.

A barra de pesquisa mostra quantos elementos foram encontrados (por exemplo, 1 of 3). Isto ajuda-o a perceber quão preciso é o seu seletor.

Exemplo prático: Galeria de memes de gatos

Agora vamos colocar este conhecimento em prática. Abra a página example.html e abra o DevTools. Tente introduzir os seletores da tabela abaixo e veja quais elementos eles encontram.

Tipos de seletores

1. Seletor universal (*)

Encontra todos os elementos da página. Use com cautela — devolverá todo o conteúdo do HTML.

Seletor: *

O que encontra: Todos os elementos sem exceção.

2. Seletor de tipo

Encontra todos os elementos com a tag HTML especificada.

Seletores: h1, p, button, div

O que encontram:

  • h1 — todos os títulos de primeiro nível
  • p — todos os parágrafos
  • button — todos os botões
  • div — todos os contentores <div>

3. Seletor de classe (.classe)

Encontra todos os elementos com a classe especificada no atributo class.

Seletores: .card, .card__title, .btn--view

O que encontram:

  • .card — todos os elementos com a classe card
  • .card__title — todos os elementos com a classe card__title
  • .btn--view — todos os elementos com a classe btn--view

4. Seletor de ID (#id)

Encontra um elemento com um id único. Só deve haver um elemento com este identificador na página.

Seletores: #salad-cat, #confused-cat, #bread-cat

O que encontram:

  • #salad-cat — o elemento com id="salad-cat"
  • #confused-cat — o elemento com id="confused-cat"
  • #bread-cat — o elemento com id="bread-cat"

5. Seletores combinados

Pode combinar tag, classe e ID para uma pesquisa mais precisa.

Seletores: h2.card__title, div.card, p.card__description, button.btn--edit

O que encontram:

  • h2.card__title — <h2> com a classe card__title
  • div.card — <div> com a classe card
  • p.card__description — <p> com a classe card__description
  • button.btn--edit — <button> com a classe btn--edit

6. Seletor de atributo ([atributo="valor"])

Encontra elementos com um atributo e valor específicos.

Seletores: [data-type="description"], [data-type="title"]

O que encontram:

  • [data-type="description"] — todos os elementos com data-type="description"
  • [data-type="title"] — elementos com data-type="title"

7. Seletor de descendente (espaço)

Encontra elementos que estão dentro de outro elemento (em qualquer nível de aninhamento).

Seletor: .card .btn

O que encontra: Todos os elementos com a classe btn que estão dentro de um elemento com a classe card.

8. Seletor de filho direto (>)

Encontra elementos que são filhos diretos de outro elemento. A pesquisa só desce um nível.

Seletor: .card__body > .card__title

O que encontra: Elementos com a classe card__title que são filhos diretos de um elemento com a classe card__body.

9. Seletor de irmão adjacente (+)

Encontra um elemento que é o irmão seguinte de outro elemento no mesmo nível de aninhamento.

Seletor: #confused-cat + .card__description

O que encontra: O parágrafo (<p>) que vem imediatamente a seguir ao elemento com id="confused-cat".

10. Pseudoclasses posicionais

Selecionam elementos com base na sua posição entre os seus irmãos.

Seletor: .card__actions :nth-child(2)

O que encontra: O segundo elemento filho dentro do elemento com a classe card__actions.

🔍 Como verificar as suas respostas

Depois de escrever um seletor, cole-o na barra de pesquisa do DevTools (Ctrl + F). A barra de pesquisa mostrará quantos elementos foram encontrados (por exemplo, 1 of 3).

  • Se estava à procura de um elemento específico único (por exemplo, por id), o resultado deve ser 1 of 1.
  • Se estava à procura de um grupo de elementos (por exemplo, todos os parágrafos com uma determinada classe), o resultado pode ser 1 of 3 ou mais — isso é normal.
  • O importante é que os elementos realçados sejam exatamente os que procurava. Verifique visualmente: os elementos corretos estão realçados na página?

Se os elementos errados estiverem realçados, refine o seletor adicionando mais condições.
