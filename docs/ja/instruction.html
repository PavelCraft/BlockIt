BlockItとは？ トップへ戻る

広告を表示するウェブサイトと一般的な広告ブロッカーは、絶え間ない「軍拡競争」を繰り広げています。サイト開発者は新しい方法で広告を表示し、ブロッカーはそれを隠す方法を見つけ出します。

BlockIt は異なるアプローチを提供します。一般的なフィルターリストに依存する代わりに、ユーザー自身が特定の要素をブロックするルールを作成します。ルールは、ユーザー自身が共有しない限り、ユーザーだけが知っているため、迂回されにくくなります。

主な機能：

  • 使いやすさ： 開発者ツールからセレクタをコピーして拡張機能に貼り付けるだけです。
  • 柔軟性：
    • CSSセレクタとXPath式の両方をサポート
    • 要素を削除するか非表示にするかを自分で決定
    • ブロックする要素と保持する要素を自分で決定
    • 保持するブロックルールと削除するルールを自分で決定
  • プライバシー： すべてのルールはブラウザにローカルに保存され、どこにも送信されません。
  • サイトごとのルールグループ化： ルールは現在のサイトとその他すべてのサイトに対して自動的にグループ化されます。これにより管理が容易になります。
  • 設定の共有： ルールをファイルにエクスポートして、他のユーザーと共有できます。
  • 多言語サポート： 拡張機能のインターフェースは、ブラウザに設定された言語に自動的に切り替わります。サポート言語：ロシア語、英語、フランス語、ドイツ語、スペイン語、ポルトガル語、中国語、日本語。お使いの言語がサポートされていない場合は、英語（デフォルト言語）で表示されます。
  • オープンソース： この拡張機能はBSD-3-Clauseライセンスの下で開発されています。プロジェクトに貢献したり、改善を提案したり、GitHubでコードを調べることができます。

クイックスタート トップへ戻る

インストール

方法1（推奨）： Chrome ウェブストア にアクセスし、BlockIt拡張機能を見つけて「インストール」をクリックします。インストール後、アドレスバーの横にあるパズルアイコンをクリックし、BlockItの横にある「ピン留め」を選択して、拡張機能をブラウザのツールバーにピン留めしてください。

方法 2（開発者向け）：GitHub からソースコードをダウンロードし、展開した拡張機能を読み込んでください。

要素をブロックする方法

  1. ブロックしたい要素を右クリックし、「検証」（または「要素を検証」）を選択します。この操作により、HTMLツリー内のその要素に直接移動します。
  2. HTMLツリーで、目的の要素を見つけます。正しい要素を選択したことを確認するには、コード行にカーソルを合わせると、ページ上の対応する要素がハイライトされます。ブロックしたいブロックを完全に覆う、最も外側の要素を選択してください。
  3. ツリー内の要素を右クリック → コピー → セレクタをコピー（または Copy selector）。XPathの場合：XPathをコピー（または Copy XPath）。
  4. BlockIt拡張機能を開き、コピーしたセレクタを入力フィールドに貼り付け、ブロックモードを選択して「ルールを追加」をクリックします。
  5. 完了！ルールがアクティブルールのリストに表示され、要素がページから消えます。
  6. 開発者ツールを閉じるには、F12 を押すか、DevToolsパネルの右上隅にある×ボタンをクリックします。

ブロックモードの意味は？

  • 削除（ほとんどの場合に適しています）：要素はページのHTMLから完全に削除され、そのスペースは他の要素のために解放されます。ただし、このオプションはレイアウトが崩れる原因になることがあります。
  • 非表示： 要素は見えなくなりますが、ページ上で同じスペースを占有し続けます。レイアウトは崩れません。

高度な機能 トップへ戻る

XPathによるブロック

XPathは、CSSセレクタが不安定な場合に、動的クラス（難読化）を使用するサイトで役立ちます。

XPathをコピーする方法：

  1. 「検証」で要素を見つけます。
  2. コード内の要素を右クリック → コピー → XPathをコピー（または Copy XPath）。
  3. コピーした式をBlockItの入力フィールドに貼り付けます。拡張機能は自動的にXPathと認識し、これのために高度なモードを有効にする必要はありません。

高度なモード

基本モードでは、拡張機能はセレクタを入力するためのシンプルなフィールドを提供します。ルールをより細かく調整し、追加のツールを使用するには、高度なモードがあります。有効にするには、拡張機能のインターフェースで対応するボタンをクリックします。

このモードでは、以下にアクセスできます：

  • HTMLパーサー： 要素のHTMLコードを貼り付けると、拡張機能がその属性から構成されるセレクタを自動的に提案します。
  • 属性の編集： 解析後、要素の属性リストが表示され、信頼性の低い属性（例：動的に生成されたクラス）を削除してセレクタを調整できます。
  • 属性の手動追加： セレクタをさらに調整したい場合、属性とその値を手動で追加できます。
  • ルールのエクスポートとインポート： ルールを他のユーザーと共有したり、デバイス間で転送したりできます。

HTMLパーサー、編集、属性の追加

これらの3つのツールは連携して機能し、構文を覚える必要なく正確なセレクタを作成するための統合ワークフローを形成します：

  1. 要素のHTMLコードをコピーします（右クリック → コピー → 要素をコピー（または Copy element））。
  2. 拡張機能で高度なモードを有効にし、HTMLコードを対応するフィールドに貼り付けます。「解析」をクリックします。拡張機能がコードを解析し、タグとそのすべての属性のリストを表示します。
  3. 提案された属性リストを編集します。 将来変更される可能性が低い属性のみを残します。例えば、動的に生成されたように見える id や class はこの目的には適していません。入力フィールドのセレクタは、変更を加えるたびに自動的に更新されます。
  4. 必要に応じて属性を手動で追加します。 提案された属性セットだけでは一意のセレクタを作成するのに不十分な場合、独自の属性を追加できます。
  5. 「ルールを追加」をクリックし、追加され、要素がページから削除されたことを確認します。

ブロックする要素を選択するためのヒント トップへ戻る

以下の方法は、最も簡単なものから高度なものへと順序付けられています。最初の方法から始めて、前の方法がうまくいかない場合は次の方法に進んでください。

1. DevToolsからセレクタをコピーする

これはほとんどのサイトで機能する最も簡単な方法です。手順は 「要素をブロックする方法」 セクションに記載されています。

2. DevToolsからXPathをコピーする

サイトの動的クラスが原因でコピーしたセレクタが機能しない場合は、この方法を使用します。XPathのコピー手順は 「XPathによるブロック」 セクションにあります。

3. HTMLパーサーを使用する（高度なモード）

この方法は、セレクタの理論は知っているが正確な構文を覚えていない場合に便利です。要素のHTMLコードを貼り付けると、拡張機能がその属性に基づいてセレクタを提案します。

4. 属性リストを編集する（高度なモード）

HTMLパーサーを使用した後、要素のすべての属性のリストが表示されます。将来変更される可能性が低い属性のみを残します。動的に生成されたクラス（意味不明な文字列）はこの目的には適していません。

5. 属性を手動で追加する（高度なモード）

自動的な方法のどれも安定したセレクタを提供しない場合は、一意の属性とその値を手動で追加して検索範囲を絞り込むことができます。

6. セレクタを手動で記述する

CSSセレクタ構文の基本的な理解が必要です。これにより、より多くの制御と安定性が得られます。基本を学ぶには、セレクターチートシート または CSSおよびXPathセレクターリファレンス（ロシア語）を参照してください。

ルールのエクスポートとインポート トップへ戻る

この機能により、ルールを他のユーザーと共有したり、コンピュータ間で転送したりできます。高度なモード で利用可能です。

  • エクスポート： すべてのルールをJSONファイルに保存します。
  • インポート： JSONファイルからルールを読み込みます。すべての現在のルールを置き換えるか、新しいルールを追加できます（重複はスキップされます）。

ルールをインポートする方法は？

  • 高度なモードで「インポート」ボタンをクリックすると、ウィンドウが開きます。「ファイルを選択」をクリックしてファイルを選択します。
  • インポートしたルールをリストに追加するか、インポートしたルールでリストを置き換えるかを選択します。希望に応じて、「すべて置き換え」または「追加」をクリックします。
  • 成功すると、確認メッセージが表示され、新しいルールが拡張機能ウィンドウのアクティブルールリストに表示されます。

トラブルシューティング（FAQ） トップへ戻る

ルールが機能しませんでした

  • 考えられる理由 #1. 選択した要素が最も外側ではない： HTMLツリーを上に移動し、親コンテナのセレクタをコピーしてみてください。
  • 考えられる理由 #2. サイトが動的クラス（難読化）を使用している： この場合、コピーしたセレクタは機能しなくなる可能性があります。XPathを使用するか、セレクタを手動で記述してください。
  • 考えられる理由 #3. 要素が動的に読み込まれる： ページが変更されると、拡張機能は自動的にルールを再適用します。それでも解決しない場合は、ページを更新してみてください。
  • 考えられる理由 #4. ルールが別のドメイン用に作成された： ルールが「このサイト用」または「他のサイト用」グループにあることを確認してください。

セレクタが要素を見つけられない

  • セレクタを確認してください： DevTools（F12）を開き、「Elements」タブに移動し、Ctrl+F（Macの場合はCmd+F）を押して、検索ボックスにセレクタを入力します。検索で何も見つからない場合、セレクタが正しくありません。
  • ページがShadow DOMを使用している： この場合、標準のセレクタは機能しない可能性があります。XPathを使用するか、シャドウルート内で要素を検索してみてください。
  • 要素がスクリプト実行後に読み込まれる： 一部の要素は遅延して表示されます。ページを更新するか、待ってみてください。

要素を削除した後、レイアウトが崩れ、広告がある時より見た目が悪くなった

  • 解決策： ルールを削除し、「非表示」 モードを選択してルールを再作成します。これにより、ページ上のスペースが保持され、レイアウトが維持されます。

セレクタが要素を多く見つけすぎる

より多くの属性を追加するか、より具体的なパスを使用してセレクタを調整します。高度なモードでは、一意の属性を手動で追加して検索範囲を絞り込むことができます。

何も効果がない

すべて試しても要素がブロックされない場合、おそらく最善の選択は、そのサイトを忘れて離れることです。😄

セレクターチートシート トップへ戻る

セレクタとは？

セレクタ は、タグ、クラス、ID、属性、またはHTML構造内の位置などのプロパティに基づいて、Webページ上の特定の要素を見つける方法です。

CSSスタイルとは異なり、BlockItではセレクタは 要素を見つけるためだけ に使用されます。色、フォント、余白を設定するのではなく、要素を 見つけて ブロックするだけです。

開発者ツールを開く方法

開発者ツール（DevTools）は、セレクタを操作するための主要なツールです。開き方は次のとおりです：

操作 結果
F12 キーを押す DevToolsパネルが開く
または Ctrl + Shift + I を押す 同じ
または要素を右クリック → 「検証」 要素がハイライトされたDevToolsが開く

開発者ツールをカスタマイズする方法

インターフェース言語

  1. DevTools（F12）を開きます。
  2. 右上隅の歯車アイコン（⚙️）をクリック → 設定。
  3. 「言語」 セクションで、ドロップダウンメニューから希望の言語を選択します。
  4. DevToolsを閉じて再度開きます。

パネルのドッキング位置

  1. DevToolsの右上隅にある3つの点（⋮）をクリックします。
  2. 以下のオプションから選択します：
    • Dock to right（デフォルト）
    • Dock to bottom — ワイドモニターを使用している場合に便利
    • Dock to left — 異なるレイアウトを希望する場合
    • Undock into separate window — 別のモニターに移動

開発者ツールでセレクタをテストする方法

セレクタが機能するかどうかを確認する最速の方法は、検索（Ctrl + F） を使用することです：

  1. DevTools（F12）を開き、「Elements」 タブに移動します。
  2. Ctrl + F（Macの場合は Cmd + F）を押します。
  3. 検索ボックスにセレクタを入力します。
  4. DevToolsがセレクタに一致するすべての要素をハイライトします。

検索バーには、見つかった要素の数が表示されます（例：1 of 3）。これにより、セレクタの精度を把握できます。

実践例：猫ミームギャラリー

それでは、この知識を実践してみましょう。example.html ページ を開き、DevToolsを開きます。下の表のセレクタを入力して、どの要素が見つかるか確認してみてください。

セレクタのタイプ

1. ユニバーサルセレクタ (*)

ページ上の すべての 要素を検索します。注意して使用してください — HTML内のすべてが返されます。

セレクタ： *

検索対象： すべての要素（例外なし）。

2. タイプセレクタ

指定されたHTMLタグを持つすべての要素を検索します。

セレクタ： h1, p, button, div

検索対象：

  • h1 — すべての第1レベルの見出し
  • p — すべての段落
  • button — すべてのボタン
  • div — すべての <div> コンテナ

3. クラスセレクタ (.class)

class 属性に指定されたクラスを持つすべての要素を検索します。

セレクタ： .card, .card__title, .btn--view

検索対象：

  • .card — クラス card を持つすべての要素
  • .card__title — クラス card__title を持つすべての要素
  • .btn--view — クラス btn--view を持つすべての要素

4. IDセレクタ (#id)

一意の id を持つ要素を検索します。ページ上にこのような要素は1つだけであるべきです。

セレクタ： #salad-cat, #confused-cat, #bread-cat

検索対象：

  • #salad-cat — id="salad-cat" を持つ要素
  • #confused-cat — id="confused-cat" を持つ要素
  • #bread-cat — id="bread-cat" を持つ要素

5. 複合セレクタ

より正確な検索のために、タグ、クラス、IDを組み合わせることができます。

セレクタ： h2.card__title, div.card, p.card__description, button.btn--edit

検索対象：

  • h2.card__title — クラス card__title を持つ <h2>
  • div.card — クラス card を持つ <div>
  • p.card__description — クラス card__description を持つ <p>
  • button.btn--edit — クラス btn--edit を持つ <button>

6. 属性セレクタ ([attribute="value"])

特定の属性と値を持つ要素を検索します。

セレクタ： [data-type="description"], [data-type="title"]

検索対象：

  • [data-type="description"] — data-type="description" を持つすべての要素
  • [data-type="title"] — data-type="title" を持つ要素

7. 子孫セレクタ（スペース）

別の要素の 内部 にある要素を検索します（任意のネストレベル）。

セレクタ： .card .btn

検索対象： クラス card を持つ要素の内部にある、クラス btn を持つすべての要素。

8. 子セレクタ (>)

別の要素の 直接の 子要素を検索します。検索は1レベル深くまでしか進みません。

セレクタ： .card__body > .card__title

検索対象： クラス card__body を持つ要素の直接の子要素である、クラス card__title を持つ要素。

9. 隣接兄弟セレクタ (+)

同じネストレベルで別の要素の 次の兄弟 である要素を検索します。

セレクタ： #confused-cat + .card__description

検索対象： id="confused-cat" を持つ要素の直後にある段落 (<p>)。

10. 位置疑似クラス

兄弟要素間での位置に基づいて要素を選択します。

セレクタ： .card__actions :nth-child(2)

検索対象： クラス card__actions を持つ要素内の2番目の子要素。

🔍 回答を確認する方法

セレクタを記述したら、DevToolsの検索バー（Ctrl + F）に貼り付けます。検索バーには、見つかった要素の数が表示されます（例：1 of 3）。

  • 特定の単一要素（例：id による）を探していた場合、結果は 1 of 1 になるはずです。
  • 要素のグループ（例：特定のクラスを持つすべての段落）を探していた場合、結果は 1 of 3 以上になることがあります — これは正常です。
  • 重要なのは、ハイライトされた要素が探していた要素であることです。視覚的に確認してください：ページ上で正しい要素がハイライトされていますか？

間違った要素がハイライトされている場合は、条件を追加してセレクタを調整してください。
