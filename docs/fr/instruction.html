Qu'est-ce que BlockIt ? Haut de page

Les sites web qui affichent des publicités et les bloqueurs de publicité populaires sont en constante « course aux armements » : les développeurs de sites trouvent sans cesse de nouveaux moyens de vous montrer des publicités, et les bloqueurs trouvent des moyens de les cacher.

BlockIt propose une approche différente. Au lieu de vous fier à des listes de filtres communes, vous créez vous-même des règles pour bloquer des éléments spécifiques. Vos règles restent connues de vous seul, à moins que vous ne décidiez de les partager, ce qui les rend beaucoup plus résistantes aux contournements.

Fonctionnalités clés :

  • Facilité d'utilisation : Il suffit de copier un sélecteur depuis les outils de développement et de le coller dans l'extension.
  • Flexibilité :
    • Supporte à la fois les sélecteurs CSS et les expressions XPath
    • Vous décidez de supprimer ou de masquer un élément
    • Vous décidez quels éléments bloquer et lesquels conserver
    • Vous décidez quelles règles de blocage garder et lesquelles supprimer
  • Respect de la vie privée : Toutes les règles sont stockées localement dans votre navigateur et ne sont envoyées nulle part.
  • Regroupement des règles par site : Les règles sont automatiquement regroupées pour le site actuel et pour tous les autres. Cela facilite leur gestion.
  • Partage des paramètres : Vous pouvez partager vos règles avec d'autres utilisateurs en les exportant dans un fichier.
  • Prise en charge multilingue : L'interface de l'extension bascule automatiquement vers la langue définie dans votre navigateur. Langues prises en charge : russe, anglais, français, allemand, espagnol, portugais, chinois et japonais. Si votre langue n'est pas prise en charge, l'interface s'affichera en anglais (langue par défaut).
  • Code source ouvert : L'extension est développée sous licence BSD-3-Clause. Vous pouvez participer au développement du projet, suggérer des améliorations et explorer le code sur GitHub.

Démarrage rapide Haut de page

Installation

Méthode 1 (recommandée) : Rendez-vous dans le Chrome Web Store, trouvez l'extension BlockIt et cliquez sur « Installer ». Après l'installation, pensez à épingler l'extension dans la barre d'outils du navigateur en cliquant sur l'icône en forme de pièce de puzzle à côté de la barre d'adresse et en sélectionnant « Épingler » à côté de BlockIt.

Méthode 2 (pour les développeurs) : Téléchargez le code source depuis GitHub et chargez l'extension non empaquetée.

Comment bloquer un élément

  1. Cliquez avec le bouton droit sur l'élément que vous souhaitez bloquer et sélectionnez « Inspecter » (ou « Inspecter l'élément »). Cette action vous mène toujours directement à l'élément dans l'arborescence HTML.
  2. Dans l'arborescence HTML, trouvez l'élément souhaité. Pour vous assurer d'avoir sélectionné le bon élément, passez votre curseur sur les lignes de code — les éléments correspondants sur la page seront mis en surbrillance. Choisissez l'élément le plus externe qui couvre entièrement le bloc que vous souhaitez bloquer.
  3. Cliquez avec le bouton droit sur l'élément dans l'arborescence → Copier → Copier le sélecteur (ou Copy selector). Pour XPath : Copier XPath (ou Copy XPath).
  4. Ouvrez l'extension BlockIt, collez le sélecteur copié dans le champ de saisie, choisissez le mode de blocage et cliquez sur « Ajouter une règle ».
  5. Terminé ! La règle apparaît dans la liste des règles actives, et l'élément disparaît de la page.
  6. Pour fermer les outils de développement, appuyez sur F12 ou cliquez sur la croix dans le coin supérieur droit du panneau DevTools.

Que signifient les modes de blocage ?

  • Supprimer (convient dans la plupart des cas) : L'élément est complètement retiré du code HTML de la page, libérant ainsi de l'espace pour d'autres éléments. Mais cette option peut parfois entraîner une rupture de la mise en page.
  • Masquer : L'élément devient invisible mais continue d'occuper le même espace sur la page. La mise en page ne se brise pas.

Fonctionnalités avancées Haut de page

Blocage avec XPath

XPath est utile sur les sites qui utilisent des classes dynamiques (obfuscation) lorsque les sélecteurs CSS sont instables.

Comment copier XPath :

  1. Trouvez l'élément via « Inspecter ».
  2. Cliquez avec le bouton droit sur l'élément dans le code → Copier → Copier XPath (ou Copy XPath).
  3. Collez l'expression copiée dans le champ de saisie de BlockIt. L'extension reconnaîtra automatiquement qu'il s'agit d'un XPath, et vous n'avez pas besoin d'activer le mode Avancé pour cela.

Mode Avancé

En mode de base, l'extension propose un simple champ pour saisir un sélecteur. Pour un réglage plus fin des règles et des outils supplémentaires, il existe le Mode Avancé. Pour l'activer, cliquez sur le bouton correspondant dans l'interface de l'extension.

Dans ce mode, vous avez accès à :

  • Analyseur HTML : Collez le code HTML d'un élément, et l'extension proposera automatiquement un sélecteur composé de ses attributs.
  • Édition des attributs : Après l'analyse, vous verrez une liste des attributs de l'élément et pourrez supprimer ceux qui ne sont pas fiables (par exemple, les classes générées dynamiquement) pour affiner le sélecteur.
  • Ajout manuel d'attributs : Vous pouvez ajouter manuellement un attribut et sa valeur si vous souhaitez affiner davantage le sélecteur.
  • Exporter et importer des règles : Partagez vos règles avec d'autres ou transférez-les entre appareils.

Analyseur HTML, édition et ajout d'attributs

Ces trois outils fonctionnent ensemble comme un flux de travail unifié pour créer des sélecteurs précis sans avoir à mémoriser la syntaxe :

  1. Copiez le code HTML de l'élément (Clic droit → Copier → Copier l'élément (ou Copy element)).
  2. Activez le mode Avancé dans l'extension et collez le code HTML dans le champ correspondant. Cliquez sur « Analyser ». L'extension analysera le code et vous montrera la balise et la liste de tous ses attributs.
  3. Modifiez la liste des attributs proposés. Conservez uniquement les attributs qui ont le moins de chances de changer à l'avenir. Par exemple, les id et les class qui ressemblent à du charabia généré dynamiquement sont de mauvais choix pour cela. Le sélecteur dans le champ de saisie sera automatiquement mis à jour à chaque modification que vous apporterez.
  4. Ajoutez des attributs manuellement si nécessaire. Si l'ensemble d'attributs suggéré ne suffit pas à créer un sélecteur unique, vous pouvez ajouter le vôtre.
  5. Cliquez sur « Ajouter une règle » et confirmez qu'elle a été ajoutée et que l'élément a bien été supprimé de la page.

Conseils pour choisir un élément à bloquer Haut de page

Les méthodes ci-dessous sont classées de la plus simple à la plus avancée. Commencez par la première et passez à la suivante si la précédente ne fonctionne pas.

1. Copier le sélecteur depuis DevTools

C'est la méthode la plus simple qui fonctionne pour la plupart des sites. Les instructions sont décrites dans la section « Comment bloquer un élément ».

2. Copier XPath depuis DevTools

Utilisez cette méthode si le sélecteur copié ne fonctionne pas à cause de classes dynamiques sur le site. Les instructions pour copier XPath se trouvent dans la section « Blocage avec XPath ».

3. Utiliser l'analyseur HTML (en mode Avancé)

Cette méthode est pratique si vous connaissez la théorie des sélecteurs mais ne vous souvenez pas de la syntaxe exacte. Vous collez le code HTML d'un élément, et l'extension propose un sélecteur basé sur ses attributs.

4. Modifier la liste des attributs (en mode Avancé)

Après avoir utilisé l'analyseur HTML, vous verrez une liste de tous les attributs de l'élément. Conservez uniquement ceux qui ont le moins de chances de changer à l'avenir. Les classes générées dynamiquement (charabia) sont de mauvais choix.

5. Ajouter des attributs manuellement (en mode Avancé)

Si aucune des méthodes automatiques ne fournit un sélecteur stable, vous pouvez ajouter manuellement un attribut unique et sa valeur pour affiner la recherche.

6. Écrire un sélecteur manuellement

Nécessite une compréhension de base de la syntaxe des sélecteurs CSS. Cela vous donne plus de contrôle et de stabilité. Pour apprendre les bases, consultez l'Aide-mémoire des sélecteurs ou le Référence des sélecteurs CSS et XPath (en russe).

Exporter et importer des règles Haut de page

Cette fonctionnalité vous permet de partager des règles avec d'autres ou de les transférer entre ordinateurs. Disponible en mode Avancé.

  • Exporter : Sauvegarde toutes vos règles dans un fichier JSON.
  • Importer : Charge des règles à partir d'un fichier JSON. Vous pouvez remplacer toutes les règles actuelles ou en ajouter de nouvelles (les doublons seront ignorés).

Comment importer des règles ?

  • En mode Avancé, cliquez sur le bouton "Importer", une fenêtre s'ouvre, cliquez sur "Choisir un fichier" et sélectionnez le fichier.
  • Choisissez l'option : ajouter les règles importées à votre liste ou remplacer votre liste par les règles importées. Selon ce que vous voulez, cliquez sur "Remplacer tout" ou "Ajouter".
  • Si tout s'est bien passé, vous verrez un message de confirmation et les nouvelles règles apparaîtront dans votre liste de règles actives dans la fenêtre de l'extension.

Résolution des problèmes (FAQ) Haut de page

Ma règle n'a pas fonctionné

  • Raison possible n°1. L'élément choisi n'est pas le plus externe : Essayez de remonter dans l'arborescence HTML et de copier un sélecteur pour le conteneur parent.
  • Raison possible n°2. Le site utilise des classes dynamiques (obfuscation) : Dans ce cas, le sélecteur copié peut cesser de fonctionner. Utilisez XPath ou écrivez un sélecteur manuellement.
  • Raison possible n°3. L'élément est chargé dynamiquement : L'extension réapplique automatiquement les règles lorsque la page change. Si cela n'a pas aidé, essayez d'actualiser la page.
  • Raison possible n°4. La règle a été créée pour un autre domaine : Vérifiez que la règle se trouve dans le groupe « Pour ce site » ou « Pour les autres sites ».

Le sélecteur ne trouve aucun élément

  • Vérifiez votre sélecteur : Ouvrez DevTools (F12), passez à l'onglet « Elements », appuyez sur Ctrl+F (ou Cmd+F sur Mac) et entrez votre sélecteur dans la barre de recherche. Si la recherche ne trouve rien, votre sélecteur est incorrect.
  • La page utilise Shadow DOM : Dans ce cas, les sélecteurs standard peuvent ne pas fonctionner. Essayez d'utiliser XPath ou de rechercher l'élément à l'intérieur de la racine fantôme.
  • L'élément se charge après l'exécution du script : Certains éléments apparaissent avec un délai. Essayez d'actualiser la page ou d'attendre.

Après la suppression d'un élément, la mise en page s'est brisée et a l'air pire qu'avec la publicité

  • Solution : Supprimez la règle et recréez-la, mais sélectionnez le mode « Masquer ». Cela préserve l'espace sur la page et maintient la mise en page intacte.

Le sélecteur trouve trop d'éléments

Affinez le sélecteur en ajoutant plus d'attributs ou en utilisant un chemin plus spécifique. En mode Avancé, vous pouvez ajouter manuellement un attribut unique pour affiner la recherche.

Rien ne fonctionne

Si vous avez tout essayé et que l'élément refuse obstinément de se bloquer, peut-être que la meilleure chose à faire est de pisser sur ce site, de le quitter et d'oublier qu'il existe. 😄

Aide-mémoire des sélecteurs Haut de page

Que sont les sélecteurs ?

Les sélecteurs sont un moyen de trouver un élément spécifique sur une page web en fonction de ses propriétés : balise, classe, identifiant, attributs ou position dans la structure HTML.

Contrairement aux styles CSS, où les sélecteurs sont utilisés pour appliquer une mise en forme, dans BlockIt, les sélecteurs sont utilisés uniquement pour trouver des éléments. Nous ne définissons pas de couleurs, de polices ou de marges — nous trouvons simplement l'élément pour le bloquer.

Comment ouvrir les outils de développement

Les outils de développement (DevTools) sont l'outil principal pour travailler avec les sélecteurs. Voici comment les ouvrir :

Action Résultat
Appuyez sur F12 Le panneau DevTools s'ouvre
Ou appuyez sur Ctrl + Shift + I Pareil
Ou faites un clic droit sur un élément → « Inspecter » DevTools s'ouvre avec l'élément surligné

Comment personnaliser les outils de développement

Langue de l'interface

  1. Ouvrez DevTools (F12).
  2. Cliquez sur l'icône d'engrenage (⚙️) dans le coin supérieur droit → Paramètres.
  3. Dans la section « Langue », sélectionnez votre langue préférée dans le menu déroulant.
  4. Fermez et rouvrez DevTools.

Position du panneau

  1. Cliquez sur les trois points (⋮) dans le coin supérieur droit de DevTools.
  2. Choisissez l'une des options :
    • Dock to right (par défaut)
    • Dock to bottom — pratique si vous avez un moniteur large
    • Dock to left — si vous préférez une disposition différente
    • Undock into separate window — déplacez-le vers un autre moniteur

Comment tester les sélecteurs dans les outils de développement

Le moyen le plus rapide de vérifier si votre sélecteur fonctionne est d'utiliser la recherche (Ctrl + F) :

  1. Ouvrez DevTools (F12) et allez dans l'onglet « Elements ».
  2. Appuyez sur Ctrl + F (ou Cmd + F sur Mac).
  3. Saisissez votre sélecteur dans la barre de recherche.
  4. DevTools mettra en surbrillance tous les éléments correspondant au sélecteur.

La barre de recherche indique combien d'éléments ont été trouvés (par exemple, 1 of 3). Cela vous aide à comprendre à quel point votre sélecteur est précis.

Exemple pratique : Galerie de chats-mèmes

Mettons maintenant ces connaissances en pratique. Ouvrez la page example.html et ouvrez DevTools. Essayez de saisir les sélecteurs du tableau ci-dessous et voyez quels éléments ils trouvent.

Types de sélecteurs

1. Sélecteur universel (*)

Trouve tous les éléments de la page. À utiliser avec précaution — il retournera tout le contenu du HTML.

Sélecteur : *

Ce qu'il trouve : Tous les éléments sans exception.

2. Sélecteur de type

Trouve tous les éléments avec la balise HTML spécifiée.

Sélecteurs : h1, p, button, div

Ce qu'ils trouvent :

  • h1 — tous les titres de premier niveau
  • p — tous les paragraphes
  • button — tous les boutons
  • div — tous les conteneurs <div>

3. Sélecteur de classe (.classe)

Trouve tous les éléments avec la classe spécifiée dans l'attribut class.

Sélecteurs : .card, .card__title, .btn--view

Ce qu'ils trouvent :

  • .card — tous les éléments avec la classe card
  • .card__title — tous les éléments avec la classe card__title
  • .btn--view — tous les éléments avec la classe btn--view

4. Sélecteur d'identifiant (#id)

Trouve un élément avec un id unique. Il ne devrait y avoir qu'un seul élément avec cet identifiant sur la page.

Sélecteurs : #salad-cat, #confused-cat, #bread-cat

Ce qu'ils trouvent :

  • #salad-cat — l'élément avec id="salad-cat"
  • #confused-cat — l'élément avec id="confused-cat"
  • #bread-cat — l'élément avec id="bread-cat"

5. Sélecteurs combinés

Vous pouvez combiner la balise, la classe et l'identifiant pour une recherche plus précise.

Sélecteurs : h2.card__title, div.card, p.card__description, button.btn--edit

Ce qu'ils trouvent :

  • h2.card__title — <h2> avec la classe card__title
  • div.card — <div> avec la classe card
  • p.card__description — <p> avec la classe card__description
  • button.btn--edit — <button> avec la classe btn--edit

6. Sélecteur d'attribut ([attribut="valeur"])

Trouve les éléments avec un attribut et une valeur spécifiques.

Sélecteurs : [data-type="description"], [data-type="title"]

Ce qu'ils trouvent :

  • [data-type="description"] — tous les éléments avec data-type="description"
  • [data-type="title"] — les éléments avec data-type="title"

7. Sélecteur de descendant (espace)

Trouve les éléments qui sont à l'intérieur d'un autre élément (à n'importe quel niveau d'imbrication).

Sélecteur : .card .btn

Ce qu'il trouve : Tous les éléments avec la classe btn qui sont à l'intérieur d'un élément avec la classe card.

8. Sélecteur d'enfant direct (>)

Trouve les éléments qui sont des enfants directs d'un autre élément. La recherche ne descend que d'un seul niveau.

Sélecteur : .card__body > .card__title

Ce qu'il trouve : Les éléments avec la classe card__title qui sont des enfants directs d'un élément avec la classe card__body.

9. Sélecteur de frère adjacent (+)

Trouve un élément qui est le frère suivant d'un autre élément au même niveau d'imbrication.

Sélecteur : #confused-cat + .card__description

Ce qu'il trouve : Le paragraphe (<p>) qui suit immédiatement l'élément avec id="confused-cat".

10. Pseudo-classes de position

Sélectionne les éléments en fonction de leur position parmi leurs frères et sœurs.

Sélecteur : .card__actions :nth-child(2)

Ce qu'il trouve : Le deuxième enfant à l'intérieur de l'élément avec la classe card__actions.

🔍 Comment vérifier vos réponses

Une fois que vous avez écrit un sélecteur, collez-le dans la barre de recherche de DevTools (Ctrl + F). La barre de recherche indiquera combien d'éléments ont été trouvés (par exemple, 1 of 3).

  • Si vous cherchiez un élément spécifique unique (par exemple, par id), le résultat devrait être 1 of 1.
  • Si vous cherchiez un groupe d'éléments (par exemple, tous les paragraphes avec une certaine classe), le résultat peut être 1 of 3 ou plus — c'est normal.
  • Le plus important est que les éléments surlignés soient exactement ceux que vous recherchiez. Vérifiez visuellement : les bons éléments sont-ils surlignés sur la page ?

Si les mauvais éléments sont surlignés, affinez le sélecteur en ajoutant plus de conditions.
