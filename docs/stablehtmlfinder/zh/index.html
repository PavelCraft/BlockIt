如何使用稳定性地图

StableHTMLFinder 比较多次页面加载，显示在所有观察中保持稳定的元素和特征，帮助高级用户创建不依赖随机变化的类、ID 或结构的选择器。

典型流程

  1. 打开包含所需元素的页面。
  2. 选择加载次数。快速查看通常两次即可；次数越多，地图越准确。
  3. 启动分析。每次加载后，扩展程序会等待设定时间，让页面完成常规内容的构建。
  4. 展开分支或使用搜索在地图中找到元素。
  5. 打开 ⋮ ，阅读特征的文字说明，然后复制 CSS 选择器或 BlockIt 规则。
  6. 将结果粘贴到 BlockIt 的相应字段，并在页面上测试。

加载次数越多，将偶然匹配误认为稳定特征的风险越低。例如动态 ID 中两个字母可能偶然两次相同，但通常不会在更多次加载中持续。

如何阅读稳定性地图

地图的每一行对应一个 HTML 元素。缩进表示已确认的页面结构：缩进元素是上方元素的后代。地图只显示在所有加载中确认稳定的特征。未显示的类、属性或树结构可能仍在页面中，只是观察之间发生了变化。

  • <div>, <a>, <section> — 稳定的标签名。
  • id="menu" — 属性名及完整值在每次加载中均匹配。
  • data-*, *-label, *test* — 只有属性名的一部分稳定：分别表示以 data-开头、以 -label 结尾或包含 test.
  • id^="prefix" — 属性值以指定文本开头； id$="suffix" — 以该文本结尾； id*="part" — 包含该文本。单独的 = 且不带 ^, $ 或 * ）表示完全匹配。
  • 没有值的属性名 表示属性本身稳定存在，但其值发生变化或未获确认。
  • class （3 个类） 表示类的数量稳定，但类名或完整 class.
  • 属性右侧的文本 — 元素稳定的自身文本。“展开”按钮可显示全文。
  • iframe, iframe document 和 #shadow-root 标记特殊嵌套页面部分的边界，其内容在地图的独立分支中继续。
  • <...> 表示发生变化或匹配不确定的结构部分，其下方可能再次出现已确认的稳定片段。

绿色行表示已确认元素。浅绿色表示可能匹配，或变化结构后的稳定片段。橙色边框表示搜索匹配项，更亮的边框表示当前匹配项。

点击 ⋮ 后，选择器或规则说明可能显示其他已确认特征：确切的属性数和类数、自身文本、同级位置、结果序号，以及与父级、祖先、子级、后代或同级元素的关系。即使地图行中未单独显示，这些特征也可用于细化结果。

搜索地图

搜索框可以查找节点显示文本、标签名、属性、属性值和元素文本。也可以粘贴从 DevTools 复制的 HTML，扩展程序会将其与地图分支匹配。普通 CSS 选择器会在最新保存的页面快照中执行并高亮关联元素。

字段旁的箭头用于切换匹配项。搜索不会隐藏树的其他部分，因此可以查看结果的祖先和后代。

CSS 选择器还是 BlockIt 规则？

如果使用的是清晰可靠的特征（稳定 ID、属性名、固定值或明确结构），请优先使用 CSS 选择器。标准 CSS 更简单，通常也更快。

当 CSS 不够用时，请使用 BlockIt 规则，例如需要考虑类或属性数量、动态属性名、自身文本或结果序号。规则功能更强，但可能稍慢。

地图会自动生成建议，但此功能仍在改进。请务必验证并阅读文字说明。粗体警告表示无法确认结果的唯一性。

为什么不公开源代码仓库

本扩展帮助用户理解不断变化的网站标记。公开详细算法会让服务商更容易有意干扰稳定性地图，因此不公开源代码仓库。这不影响 Chrome 应用商店的审核，也不承诺完全的技术保密。

与 BlockIt 的关系

StableHTMLFinder 查找可靠特征； BlockIt 应用生成的规则并隐藏或删除匹配元素。当从 DevTools 复制的选择器在刷新后失效时，两者配合很有用。

BlockIt 是独立扩展，生成地图不需要它。
