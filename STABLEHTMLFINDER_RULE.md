# Формат правила StableHTMLFinder → BlockIt

BlockIt распознаёт текст, начинающийся с `SHF1:`. После префикса должен идти
JSON. Минимальное правило:

```text
SHF1:{"version":1,"target":{"type":"css","selector":".ya-unit-wrapper"}}
```

Допустимые значения `target.type`: `css` и `xpath`. BlockIt сохраняет исходный
JSON вместе с правилом и выполняет `target` в каждом доступном iframe и во всех
открытых или перехваченных закрытых Shadow Root.

Поля, добавленные StableHTMLFinder для описания стабильности, iframe-пути или
запасных локаторов, BlockIt пока сохраняет, но не интерпретирует. Это позволяет
расширять формат без несовместимости с уже сохранёнными правилами.
